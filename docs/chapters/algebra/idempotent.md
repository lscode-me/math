# Глава 2.6. Идемпотентные функции и функциональные уравнения

## 2.6.1. Что такое функциональное уравнение

До сих пор мы искали **числа**, удовлетворяющие уравнению: $x^2 - 5 = 0$, $\cos x = x$. Но можно поставить задачу иначе: найти **функцию**, удовлетворяющую некоторому уравнению.

!!! important "Функциональное уравнение"
    **Функциональное уравнение** — это уравнение, в котором неизвестной является функция, а само уравнение связывает значения этой функции в разных точках.

Простейший пример: найти все функции $f\colon \mathbb{R} \to \mathbb{R}$, для которых

$$f(x + y) = f(x) + f(y) \quad \text{для всех } x, y \in \mathbb{R}.$$

Это знаменитое **уравнение Коши**. Интуитивно ответ очевиден: $f(x) = cx$ для некоторой константы $c$. Но доказательство этого факта — отдельная история с неожиданным поворотом.

Функциональные уравнения используются повсюду:

- В физике (уравнения симметрии),
- В теории вероятностей (уравнения на характеристические функции),
- В информатике (свойства чистых функций),
- На олимпиадах (ИМО, всероссийские олимпиады).

## 2.6.2. Уравнение Коши: $f(x+y) = f(x) + f(y)$

### Первые следствия

Не зная ответа заранее, выведем свойства $f$ из одного только уравнения.

**Шаг 1.** Подставим $x = y = 0$:

$$f(0 + 0) = f(0) + f(0) \quad \Rightarrow \quad f(0) = 2f(0) \quad \Rightarrow \quad f(0) = 0.$$

**Шаг 2.** Подставим $y = -x$:

$$f(0) = f(x) + f(-x) \quad \Rightarrow \quad f(-x) = -f(x).$$

Функция нечётная — как и ожидалось для $f(x) = cx$.

**Шаг 3.** По индукции, для натурального $n$:

$$f(nx) = f(x + x + \cdots + x) = nf(x).$$

Значит, $f(n) = nf(1)$. Обозначим $c = f(1)$, тогда $f(n) = cn$ для всех $n \in \mathbb{N}$.

**Шаг 4.** Для рационального $x = p/q$:

$$q \cdot f\!\left(\tfrac{p}{q}\right) = f\!\left(q \cdot \tfrac{p}{q}\right) = f(p) = cp \quad \Rightarrow \quad f\!\left(\tfrac{p}{q}\right) = c \cdot \tfrac{p}{q}.$$

Итого: на рациональных числах $f(x) = cx$ однозначно. Но что происходит с иррациональными числами?

### Неожиданный поворот: патологические решения

Если не требовать никакой регулярности (непрерывности, монотонности, ограниченности на промежутке), то у уравнения Коши есть **патологические решения** — функции, принимающие на любом открытом интервале любые вещественные значения.

Их существование нельзя доказать конструктивно: оно опирается на аксиому выбора и требует выбора базиса Гамеля (базиса $\mathbb{R}$ над $\mathbb{Q}$). Такие функции существуют «в принципе», но невозможно написать ни одной явной формулы.

!!! important "Теорема"
    Функциональное уравнение $f(x+y) = f(x) + f(y)$ при дополнительном условии **непрерывности** (или монотонности, или ограниченности на промежутке) имеет единственное семейство решений: $f(x) = cx$, $c \in \mathbb{R}$.

Это поучительный пример: «очевидный» ответ $f(x) = cx$ требует дополнительных условий. Без них математика допускает монстров.

## 2.6.3. Уравнение Йенсена и выпуклость

**Уравнение Йенсена** — ближайший родственник уравнения Коши:

$$f\!\left(\frac{x+y}{2}\right) = \frac{f(x) + f(y)}{2}.$$

Читается: «значение функции в средней точке равно среднему значений на концах». Это **условие аффинности**. При условии непрерывности решения снова только $f(x) = ax + b$.

Но если заменить $=$ на $\leq$, получаем **неравенство Йенсена** — определение **выпуклой** функции:

$$f\!\left(\frac{x+y}{2}\right) \leq \frac{f(x) + f(y)}{2}.$$

Примеры выпуклых функций: $x^2$, $e^x$, $-\ln x$ (при $x>0$). Неравенство Йенсена для выпуклых функций $f$ и произвольных весов:

$$f\!\left(\sum_{i=1}^n \lambda_i x_i\right) \leq \sum_{i=1}^n \lambda_i f(x_i), \quad \lambda_i \geq 0,\; \sum \lambda_i = 1$$

Это мощный инструмент для доказательства неравенств. Например, из выпуклости $-\ln$ получаем неравенство AM-GM:

$$-\ln\!\left(\frac{x_1 + \cdots + x_n}{n}\right) \leq \frac{-\ln x_1 - \cdots - \ln x_n}{n} = -\ln\!\sqrt[n]{x_1 \cdots x_n}$$

и значит $\frac{x_1 + \cdots + x_n}{n} \geq \sqrt[n]{x_1 \cdots x_n}$.

## 2.6.4. Идемпотентность: $f(f(x)) = f(x)$

Перейдём к особому классу функций, определяемых функциональным уравнением:

$$f(f(x)) = f(x)$$

Функция $f$ называется **идемпотентной** (от лат. *idem* — тот же, *potens* — мощный), если применение её **дважды** даёт то же, что применение **один раз**. Иначе говоря: если $x$ уже находится в «образе» функции $f$, то $f$ его не изменяет.

### Геометрический смысл

Пусть $\mathrm{Im}(f) = \{f(x) : x \in \mathbb{R}\}$ — образ функции. Идемпотентность означает: $f$ действует как **тождественное отображение на своём собственном образе**. Подставив $y = f(x)$: $f(y) = f(f(x)) = f(x) = y$. Каждая точка образа является **неподвижной точкой** $f$.

### Примеры идемпотентных функций

**Пример 1. Модуль.** $f(x) = |x|$.

$$f(f(x)) = ||x|| = |x| = f(x). \checkmark$$

Образ — $[0, +\infty)$, и на нём $|x| = x$.

**Пример 2. Округление вниз (floor).** $f(x) = \lfloor x \rfloor$.

$$f(f(x)) = \lfloor \lfloor x \rfloor \rfloor = \lfloor x \rfloor = f(x). \checkmark$$

Целые числа — неподвижные точки: $\lfloor n \rfloor = n$.

**Пример 3. Округление вверх (ceil).** $f(x) = \lceil x \rceil$ — аналогично.

**Пример 4. Проекция.** В геометрии: ортогональная проекция на прямую $\ell$ — идемпотентна. Если точка уже на $\ell$, проекция не меняет её.

**Пример 5. Функция знака.** $f(x) = \mathrm{sgn}(x) \in \{-1, 0, 1\}$.

$$f(f(x)) = \mathrm{sgn}(\mathrm{sgn}(x)) = \mathrm{sgn}(x). \checkmark$$

(Знак числа из $\{-1, 0, 1\}$ равен самому числу.)

**Контрпример.** $f(x) = x^2$ — **не** идемпотентна: $f(f(2)) = f(4) = 16 \neq 4 = f(2)$.

## 2.6.5. Инволюция: $f(f(x)) = x$

Смежное понятие — **инволюция**: функция, которая при двукратном применении возвращает исходное значение.

$$f(f(x)) = x$$

Это значит, что $f$ — **обратна сама себе**: $f = f^{-1}$.

### Примеры инволюций

| Функция | Пояснение |
|---------|-----------|
| $f(x) = -x$ | Отражение относительно нуля |
| $f(x) = \frac{1}{x}$ (при $x \neq 0$) | Обращение: $\frac{1}{1/x} = x$ |
| $f(x) = a - x$ | Отражение относительно $a/2$ |
| $f(x) = \frac{c}{x}$ (при $x \neq 0$) | Обобщённое обращение |
| Комплексное сопряжение $f(z) = \bar{z}$ | $\overline{\bar{z}} = z$ |

В геометрии инволюцией является центральная симметрия, осевая симметрия, инверсия. В криптографии инволютивный шифр — тот, что расшифровывает сам себя (применить операцию дважды = ничего не сделать).

### Идемпотентность vs инволюция

Две похожие формулы — принципиально разные объекты:

| | Уравнение | Смысл |
|---|---|---|
| Идемпотентность | $f(f(x)) = f(x)$ | Повторное применение ничего не меняет |
| Инволюция | $f(f(x)) = x$ | Повторное применение возвращает к началу |

Идемпотентная функция «схлопывает» множество в образ и там стоит на месте. Инволютивная функция «качается» туда-обратно.

!!! note "Тождественная функция"
    Тождественная функция $f(x) = x$ удовлетворяет **обоим** уравнениям одновременно: $f(f(x)) = x = f(x)$. Это единственная функция, являющаяся и идемпотентной, и инволютивной.

## 2.6.6. Идемпотентность в информатике

Понятие идемпотентности активно используется в программировании и системном дизайне.

**HTTP-методы.** Метод `GET` идемпотентен: сколько раз ни запрашивай страницу, сервер не меняется. Метод `PUT` (обновить ресурс) тоже идемпотентен: повторный `PUT` с теми же данными не изменит результат. А метод `POST` (создать новый ресурс) — **не** идемпотентен: каждый вызов создаёт новый объект.

**Чистые функции.** В функциональном программировании функция без побочных эффектов — функция, результат которой зависит только от аргументов. Идемпотентная чистая функция дополнительно гарантирует: повторный вызов с тем же аргументом не изменит ничего.

**Базы данных.** Операция `INSERT OR IGNORE` идемпотентна: повторное выполнение не создаёт дублей. `DELETE` тоже идемпотентен: удалить уже удалённую запись — ничего не произойдёт.

**Распределённые системы.** При ненадёжной сети запрос может дойти дважды. Если операция идемпотентна, это не страшно — повторное выполнение ничего не сломает. Поэтому проектирование идемпотентных API — важная практика.

!!! tip "Математика в коде"
    Идемпотентность — пример того, как чисто математическое понятие оказывается фундаментальным при проектировании надёжных программных систем. Уравнение $f(f(x)) = f(x)$ — это не только математическая абстракция, но и конкретное требование к API.

## 2.6.7. Олимпиадные функциональные уравнения

На олимпиадах часто встречаются задачи вида: «найти все функции $f$, удовлетворяющие...». Стандартный арсенал приёмов:

**Подстановки.** Выбрать удобные значения ($x = 0$, $y = 0$, $y = x$, $x = 1$, ...) и вывести свойства $f$.

**Инъективность и сюръективность.** Доказать, что $f$ является инъекцией (из $f(a) = f(b)$ следует $a = b$) или сюръекцией (любое значение достигается).

**Монотонность.** Показать, что $f$ монотонна, а затем использовать плотность рациональных чисел.

**Разбор случаев.** Нередко подстановки дают несколько вариантов, каждый из которых нужно проверить.

### Пример олимпиадной задачи

> Найдите все функции $f\colon \mathbb{R} \to \mathbb{R}$, удовлетворяющие:
> $$f(f(x) - y) = f(x) + f(f(y) - f(-x)) - x \quad \text{для всех } x, y \in \mathbb{R}.$$

Такие задачи решаются серией подстановок, шаг за шагом сужающих класс кандидатов. Типичный ответ — линейная функция $f(x) = x + c$ или $f(x) = -x + c$, но путь к нему нетривиален.

---

!!! abstract "Резюме главы"
    - **Функциональное уравнение** — уравнение, где неизвестна функция, а не число
    - **Уравнение Коши** $f(x+y) = f(x) + f(y)$ при условии непрерывности имеет единственные решения $f(x) = cx$; без регулярности существуют патологические решения
    - **Неравенство Йенсена** обобщает уравнение Коши до выпуклых функций и является источником многих классических неравенств
    - **Идемпотентность** ($f(f(x)) = f(x)$): повторное применение ничего не меняет; неподвижные точки — весь образ функции. Примеры: $|x|$, $\lfloor x \rfloor$, проекция
    - **Инволюция** ($f(f(x)) = x$): функция обратна сама себе. Примеры: $-x$, $1/x$, симметрии
    - Идемпотентность — ключевая концепция в информатике: HTTP-методы, базы данных, распределённые системы
