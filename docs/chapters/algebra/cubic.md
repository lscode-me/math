# Глава 2.3. Кубические уравнения

## 2.3.1. От квадрата — к кубу

Квадратные уравнения решали ещё вавилоняне. Естественный следующий вопрос:

$$ax^3 + bx^2 + cx + d = 0, \quad a \neq 0$$

Можно ли найти **общую формулу** для корней через коэффициенты, используя только арифметику и радикалы? Ответ: да, но формула устроена существенно сложнее.

---

## 2.3.2. Геометрический подход: объём куба

Как квадратное уравнение связано с площадью квадрата, так кубическое — с объёмом куба.

### Задача

> Найти сторону куба, если его объём плюс три грани равны $2$.

На современном языке: $x^3 + 3x = 2$, или $x^3 + 3x - 2 = 0$.

### Геометрическая идея Кардано

Представим сторону $x$ как разность двух отрезков: $x = t - s$. Тогда:

$$(t - s)^3 = t^3 - 3t^2 s + 3ts^2 - s^3 = t^3 - s^3 - 3ts(t - s)$$

Подставим $x = t - s$:

$$x^3 = t^3 - s^3 - 3ts \cdot x$$

$$x^3 + 3ts \cdot x = t^3 - s^3$$

Сравним с уравнением $x^3 + px + q = 0$:

$$\begin{cases} 3ts = p \\ t^3 - s^3 = -q \end{cases}$$

Итого:

$$ts = \frac{p}{3}, \qquad t^3 - s^3 = -q$$

Из первого: $s = \frac{p}{3t}$. Подставим во второе — и получим **квадратное** уравнение относительно $t^3$! Именно эта идея лежит в основе формулы Кардано.

---

## 2.3.3. Избавление от квадратного члена (депрессия)

Общее кубическое уравнение $ax^3 + bx^2 + cx + d = 0$.

**Шаг 1.** Делим на $a$:

$$x^3 + \frac{b}{a}x^2 + \frac{c}{a}x + \frac{d}{a} = 0$$

Обозначим $x^3 + Bx^2 + Cx + D = 0$.

**Шаг 2. Подстановка Кардано — Тарталья.** Замена $x = y - \frac{B}{3}$ убирает квадратный член:

$$\left(y - \frac{B}{3}\right)^3 + B\left(y - \frac{B}{3}\right)^2 + C\left(y - \frac{B}{3}\right) + D = 0$$

После раскрытия:

$$y^3 + py + q = 0$$

где:

$$p = C - \frac{B^2}{3}, \qquad q = D - \frac{BC}{3} + \frac{2B^3}{27}$$

Это **неполное** (депрессированное) кубическое уравнение — без $y^2$. Вся задача сводится к решению уравнений такого вида.

!!! tip "Аналогия с квадратным"
    Подстановка $x = y - \frac{B}{3}$ для кубического уравнения — аналог выделения полного квадрата: мы «сдвигаем» переменную, чтобы упростить структуру.

---

## 2.3.4. Формула Кардано

Решаем депрессированное уравнение:

$$y^3 + py + q = 0$$

### Вывод

Ищем $y = t - s$, где $ts = \frac{p}{3}$. Тогда (как показано в § 2.3.2):

$$t^3 - s^3 = -q, \qquad t^3 \cdot s^3 = \frac{p^3}{27}$$

Величины $t^3$ и $s^3$ — корни **квадратного** уравнения (по теореме Виета!):

$$z^2 + qz - \frac{p^3}{27} = 0$$

Его дискриминант:

$$\Delta = q^2 + \frac{4p^3}{27}$$

Корни:

$$t^3 = \frac{-q + \sqrt{\Delta}}{2}, \qquad s^3 = \frac{-q - \sqrt{\Delta}}{2}$$

Традиционно обозначают:

$$Q = \frac{q^2}{4} + \frac{p^3}{27}$$

Тогда:

$$t^3 = -\frac{q}{2} + \sqrt{Q}, \qquad s^3 = -\frac{q}{2} - \sqrt{Q}$$

И наконец:

$$\boxed{y = \sqrt[3]{-\frac{q}{2} + \sqrt{Q}} + \sqrt[3]{-\frac{q}{2} - \sqrt{Q}}, \qquad Q = \frac{q^2}{4} + \frac{p^3}{27}}$$

Это и есть **формула Кардано**.

!!! warning "Обратите внимание"
    В формуле два кубических корня **не** независимы: их произведение $t \cdot s$ должно быть вещественным и равным $\frac{p}{3}$.

### Пример 1: $x^3 - 4x + 3 = 0$

Уравнение уже депрессированное (нет $x^2$): $p = -4$, $q = 3$.

$$Q = \frac{9}{4} + \frac{(-4)^3}{27} = \frac{9}{4} - \frac{64}{27} = \frac{243 - 256}{108} = -\frac{13}{108}$$

$Q < 0$ — casus irreducibilis! Но подождём — попробуем сначала найти целый корень подбором.

$x = 1$: $1 - 4 + 3 = 0$. ✓

Делим на $(x - 1)$: $x^3 - 4x + 3 = (x - 1)(x^2 + x - 3)$.

Оставшееся квадратное: $x = \frac{-1 \pm \sqrt{13}}{2}$.

Итого три **вещественных** корня: $x_1 = 1$, $x_2 = \frac{-1 + \sqrt{13}}{2} \approx 1{,}303$, $x_3 = \frac{-1 - \sqrt{13}}{2} \approx -2{,}303$.

А формула Кардано для этого уравнения даёт $\sqrt{Q} = \sqrt{-\frac{13}{108}} = i\frac{\sqrt{13}}{6\sqrt{3}}$ — **мнимое число**. Подставив в формулу, получим кубические корни из комплексных чисел, которые в итоге дадут те же самые вещественные ответы. Вот она, суть casus irreducibilis: ответ простой, а путь через формулу — через комплексные числа.

### Пример 2: $y^3 + 6y - 20 = 0$

$p = 6$, $q = -20$.

$$Q = \frac{(-20)^2}{4} + \frac{6^3}{27} = \frac{400}{4} + \frac{216}{27} = 100 + 8 = 108$$

$Q > 0$ — формула работает напрямую:

$$y = \sqrt[3]{10 + \sqrt{108}} + \sqrt[3]{10 - \sqrt{108}}$$

$\sqrt{108} = 6\sqrt{3} \approx 10{,}392$

$$y = \sqrt[3]{10 + 6\sqrt{3}} + \sqrt[3]{10 - 6\sqrt{3}} \approx \sqrt[3]{20{,}392} + \sqrt[3]{-0{,}392} \approx 2{,}732 + (-0{,}732) = 2$$

Проверка: $2^3 + 6 \cdot 2 - 20 = 8 + 12 - 20 = 0$. ✓

### Пример 3: когда Кардано усложняет простое

Рассмотрим уравнение:

$$x^3 + 3x - 4 = 0$$

Подбором: $x = 1$ даёт $1 + 3 - 4 = 0$. ✓ Корень очевиден. Но формула Кардано этого «не знает» — она честно вычисляет:

$$p = 3, \quad q = -4, \quad Q = \frac{16}{4} + \frac{27}{27} = 5$$

$$x = \sqrt[3]{2 + \sqrt{5}} + \sqrt[3]{2 - \sqrt{5}}$$

Формула утверждает, что это громоздкое выражение равно $1$.

**Доказательство.** Пусть $a = \sqrt[3]{2 + \sqrt{5}}$, $\;b = \sqrt[3]{2 - \sqrt{5}}$, $\;t = a + b$.

$$ab = \sqrt[3]{(2+\sqrt{5})(2-\sqrt{5})} = \sqrt[3]{4 - 5} = \sqrt[3]{-1} = -1$$

$$a^3 + b^3 = (2 + \sqrt{5}) + (2 - \sqrt{5}) = 4$$

Используем тождество $a^3 + b^3 = (a+b)^3 - 3ab(a+b)$:

$$4 = t^3 - 3(-1)t = t^3 + 3t$$

$$t^3 + 3t - 4 = 0 \;\;\Rightarrow\;\; (t - 1)(t^2 + t + 4) = 0$$

Дискриминант квадратного: $D = 1 - 16 = -15 < 0$, вещественных корней нет. Значит $t = 1$. $\;\square$

Заметим, что $\sqrt{5} - 2 > 0$, поэтому $\sqrt[3]{2 - \sqrt{5}} = -\sqrt[3]{\sqrt{5} - 2}$, и результат можно записать иначе:

$$\sqrt[3]{\sqrt{5} + 2} - \sqrt[3]{\sqrt{5} - 2} = 1$$

!!! tip "Связь с золотым сечением"
    Число $\varphi = \frac{1+\sqrt{5}}{2}$ (золотое сечение, §3.1) обладает свойством $\varphi^2 = \varphi + 1$, откуда $\varphi^3 = \varphi^2 \cdot \varphi = (\varphi+1)\varphi = \varphi^2 + \varphi = 2\varphi + 1 = 2 + \sqrt{5}$. Значит $\sqrt[3]{2 + \sqrt{5}} = \varphi$, а $\sqrt[3]{\sqrt{5} - 2} = 1/\varphi$, и наше тождество — просто $\varphi - 1/\varphi = 1$.

Формула Кардано гарантирует нахождение корня, но не простоту записи. Метод доказательства универсален: обозначить выражение за $t$, возвести в куб, вычислить $ab$ и $a^3 + b^3$, получить уравнение на $t$.

### Полный пример: $x^3 - 3x^2 + 3 = 0$

**Шаг 1. Депрессия.** $B = -3$, подстановка $x = y + 1$:

$$p = 0 - \frac{(-3)^2}{3} = -3, \quad q = 3 - \frac{(-3)(0)}{3} + \frac{2(-3)^3}{27} = 3 + 0 - 2 = 1$$

Депрессированное уравнение: $y^3 - 3y + 1 = 0$.

**Шаг 2. Формула Кардано.**

$$Q = \frac{1}{4} + \frac{(-3)^3}{27} = \frac{1}{4} - 1 = -\frac{3}{4}$$

$Q < 0$ — **casus irreducibilis**! Формула содержит $\sqrt{-\frac{3}{4}}$, то есть **комплексные числа**. Тем не менее все три корня — вещественные. Это не ошибка формулы, а её знаменитая особенность (см. § 2.3.5).

## 2.3.5. Три случая: знак величины $Q$

Величина $Q = \frac{q^2}{4} + \frac{p^3}{27}$ играет для кубического уравнения ту же роль, что дискриминант $D$ для квадратного:

| $Q$ | Корни | Формула Кардано |
|-----|-------|-----------------|
| $Q > 0$ | Один вещественный, два комплексных | Работает напрямую |
| $Q = 0$ | Все вещественные, есть кратный | Работает (кубические корни – вещественные) |
| $Q < 0$ | **Три различных вещественных** | Даёт комплексные подкоренные — *casus irreducibilis* |

### Casus irreducibilis

Когда $Q < 0$, формула Кардано выглядит так:

$$y = \sqrt[3]{-\frac{q}{2} + i\sqrt{|Q|}} + \sqrt[3]{-\frac{q}{2} - i\sqrt{|Q|}}$$

Под кубическими корнями стоят **комплексные** числа, хотя ответ — три вещественных корня. Это не обходится: **доказано** (Вентцель, 1845), что через одни радикалы (без тригонометрии) вещественные корни в этом случае выразить невозможно.

На практике при $Q < 0$ используют **тригонометрическую формулу Виета**:

$$y_k = 2\sqrt{-\frac{p}{3}} \cos\left(\frac{1}{3}\arccos\left(\frac{3q}{2p}\sqrt{-\frac{3}{p}}\right) - \frac{2\pi k}{3}\right), \quad k = 0, 1, 2$$

## 2.3.6. Теорема Виета для кубического уравнения

Для уравнения $x^3 + Bx^2 + Cx + D = 0$ с корнями $x_1, x_2, x_3$:

$$\begin{cases} x_1 + x_2 + x_3 = -B \\ x_1 x_2 + x_1 x_3 + x_2 x_3 = C \\ x_1 x_2 x_3 = -D \end{cases}$$

Это прямое обобщение теоремы Виета: сумма корней, сумма попарных произведений, произведение корней — всё определяется коэффициентами.

## 2.3.7. Немного истории: математические дуэли

### Сципион дель Ферро (ок. 1515)

Профессор Болонского университета **Сципион дель Ферро** первым нашёл способ решения уравнений вида $x^3 + px = q$ (с положительными $p$ и $q$). Он не опубликовал открытие — в те времена университетские профессора удерживали должность через **публичные математические дуэли**. Знание формулы давало преимущество на таких состязаниях.

Перед смертью (1526) дель Ферро передал секрет своему ученику **Антонио Фиору**.

### Никколо Тарталья (1535)

Фиор вызвал на дуэль **Никколо Тарталью** — самоучку из Брешии (прозвище «Заика» — след ранения, полученного в детстве при разграблении города французами). Каждый участник дал другому 30 задач.

Фиор был уверен в победе: все его задачи сводились к кубическому уравнению. Но за несколько дней до срока Тарталья **самостоятельно переоткрыл** формулу и решил все 30 задач за 2 часа. Фиор не смог решить ни одной задачи Тартальи.

### Джероламо Кардано (1545)

**Кардано** — врач, математик, астролог, игрок — выпросил формулу у Тартальи под клятву не публиковать. Но позже Кардано узнал, что приоритет принадлежит дель Ферро, и счёл себя свободным от клятвы. В 1545 году он издал книгу ***Ars Magna*** («Великое искусство»), где изложил полное решение кубических и биквадратных уравнений.

Тарталья был в ярости. Разразилась публичная полемика. На защиту Кардано вышел его ученик **Лодовико Феррари** (который, кстати, нашёл формулу для уравнений 4-й степени — в возрасте 18 лет).

### Почему «формула Кардано»?

По справедливости формулу следовало бы назвать «формулой дель Ферро — Тартальи — Кардано». Но в науке закрепляется имя того, кто **опубликовал**.

!!! quote "Кардано, *Ars Magna* (1545)"
    «Сципион дель Ферро из Болоньи около тридцати лет назад открыл это правило и передал его Антонио Марии Фиору из Венеции, который, устроив состязание с Никколо Тартальей из Брешии, дал повод Никколо тоже найти это правило. Никколо передал его мне по моей просьбе, хотя скрыл доказательство. Опираясь на это, я нашёл доказательство, что было весьма трудно.»

## 2.3.8. Формула Кардано на практике: алгоритм

Для уравнения $ax^3 + bx^2 + cx + d = 0$:

1. **Делим на $a$:** получаем $x^3 + Bx^2 + Cx + D = 0$

2. **Депрессия:** подстановка $x = y - \frac{B}{3}$ даёт $y^3 + py + q = 0$, где:

    $$p = C - \frac{B^2}{3}, \qquad q = D - \frac{BC}{3} + \frac{2B^3}{27}$$

3. **Дискриминант:**

    $$Q = \frac{q^2}{4} + \frac{p^3}{27}$$

4. **Если $Q \geq 0$** — формула Кардано:

    $$y = \sqrt[3]{-\frac{q}{2} + \sqrt{Q}} + \sqrt[3]{-\frac{q}{2} - \sqrt{Q}}$$
    
    Остальные корни можно найти, разделив кубическое на $(y - y_1)$ и решив оставшееся квадратное.

5. **Если $Q < 0$** — тригонометрическая формула (все три корня вещественные).

6. **Обратная подстановка:** $x = y + \frac{B}{3}$ (не забыть вернуться!)

### Пример от начала до конца: $2x^3 - 6x^2 - 12x + 16 = 0$

**Шаг 1.** Делим на 2: $x^3 - 3x^2 - 6x + 8 = 0$. Здесь $B = -3$, $C = -6$, $D = 8$.

**Шаг 2.** Подстановка $x = y + 1$:

$$p = -6 - \frac{9}{3} = -9, \qquad q = 8 - \frac{(-3)(-6)}{3} + \frac{2(-27)}{27} = 8 - 6 - 2 = 0$$

Уравнение: $y^3 - 9y = 0$.

**Шаг 3.** $Q = 0 + \frac{(-9)^3}{27} = -27$. Но подождём — уравнение $y^3 - 9y = 0$ раскладывается:

$$y(y^2 - 9) = 0 \quad \Rightarrow \quad y = 0, \quad y = \pm 3$$

**Шаг 4.** Обратная подстановка $x = y + 1$:

$$x_1 = 1, \quad x_2 = 4, \quad x_3 = -2$$

Проверка: $(x-1)(x-4)(x+2) = x^3 - 3x^2 - 6x + 8$. ✓

## 2.3.9. Чего мы **не** можем для степени 5

Формулы в радикалах существуют для уравнений степеней 2, 3 и 4. Для степени 5 и выше **общей формулы нет** — это доказал **Нильс Хенрик Абель** (1824), а полную картину дала **теория Галуа** (1830-е). Конкретное уравнение 5-й степени может иметь решение в радикалах, но универсальной формулы через коэффициенты не существует.

| Степень | Формула | Автор / период |
|---------|---------|----------------|
| 2 | $\frac{-b \pm \sqrt{D}}{2a}$ | Вавилон, ~2000 до н.э. |
| 3 | Формула Кардано | Дель Ферро ~1515, Тарталья 1535, Кардано 1545 |
| 4 | Формула Феррари | Феррари 1540, опубл. Кардано 1545 |
| 5+ | **Не существует** | Абель 1824, Галуа 1832 |

---

!!! abstract "Резюме главы"
    - Любое кубическое уравнение **подстановкой** $x = y - \frac{B}{3}$ сводится к виду $y^3 + py + q = 0$
    - **Формула Кардано** выражает корень через кубические и квадратические радикалы
    - Величина $Q = \frac{q^2}{4} + \frac{p^3}{27}$ определяет характер корней
    - При $Q < 0$ (**casus irreducibilis**) все три корня вещественные, но формула содержит комплексные числа — это неизбежно
    - **Теорема Виета** обобщается: сумма корней $= -B$, сумма попарных произведений $= C$, произведение $= -D$
    - Для степени $\geq 5$ общей формулы в радикалах **не существует** (Абель — Галуа)
    - История формулы — математические дуэли, нарушенные клятвы и борьба за приоритет

## Задачи

### Базовый уровень ⭐

**2.3.1.** Проведите депрессию уравнения $x^3 + 6x^2 + 11x + 6 = 0$ (найдите $p$ и $q$).

??? note "Ответ"
    Подстановка $x = y - 2$: $p = 11 - 12 = -1$, $q = 6 - 22 + \frac{16}{27} + \ldots$ Вычислите аккуратно, получится $y^3 - y = 0$, откуда $y = 0, \pm 1$, $x = -1, -2, -3$.

**2.3.2.** Решите $x^3 - 6x^2 + 11x - 6 = 0$, зная, что один из корней — целое число. Найдите его подбором, а затем поделите на $(x - x_1)$.

??? note "Ответ"
    $x = 1$: $1 - 6 + 11 - 6 = 0$. Деление: $x^2 - 5x + 6 = 0$, корни $2$ и $3$. Ответ: $x \in \{1, 2, 3\}$.

**2.3.3.** Примените формулу Кардано к уравнению $y^3 + 6y - 2 = 0$. Вычислите $Q$ и запишите ответ в виде суммы кубических корней.

??? note "Ответ"
    $Q = 1 + 8 = 9$. $y = \sqrt[3]{1 + 3} + \sqrt[3]{1 - 3} = \sqrt[3]{4} + \sqrt[3]{-2} = \sqrt[3]{4} - \sqrt[3]{2} \approx 0{,}327$.

### Средний уровень ⭐⭐

**2.3.4.** Решите $x^3 - 3x^2 - 9x + 27 = 0$ от начала до конца (депрессия → формула → обратная подстановка).

??? note "Ответ"
    $x = y + 1$: $y^3 - 12y + 16 = 0$. $Q = 64 - 64 = 0$. $y = 2\sqrt[3]{-8} = -4$ (кратный корень). Деление: $y^2 - 4y + 4 = 0$, $y = 2$ (кратность 2). $x \in \{-3, 3, 3\}$.

**2.3.5.** С помощью теоремы Виета для кубического уравнения найдите $x_1^2 + x_2^2 + x_3^2$, если $x_1, x_2, x_3$ — корни $x^3 - 4x^2 + 5x - 2 = 0$.

??? note "Ответ"
    $x_1^2 + x_2^2 + x_3^2 = (x_1 + x_2 + x_3)^2 - 2(x_1x_2 + x_1x_3 + x_2x_3) = 16 - 10 = 6$.

**2.3.6.** Покажите, что уравнение $y^3 - 3y + 1 = 0$ попадает в casus irreducibilis (вычислите $Q$), и найдите один корень с точностью до 0,01 с помощью тригонометрической формулы.

??? note "Ответ"
    $Q = \frac{1}{4} - 1 = -\frac{3}{4} < 0$. $y_0 = 2\cos\left(\frac{1}{3}\arccos\left(-\frac{1}{2}\right)\right) = 2\cos\frac{2\pi}{9} \approx 1{,}532$.

### Олимпиадный уровень ⭐⭐⭐

**2.3.7.** Используя метод из Примера 3 (§2.3.4), докажите, что $\sqrt[3]{7 + 5\sqrt{2}} + \sqrt[3]{7 - 5\sqrt{2}} = 2$.

??? note "Подсказка"
    $ab = \sqrt[3]{49 - 50} = -1$, $\;a^3 + b^3 = 14$. Если $t = a+b$, то $t^3 = 14 - 3t$, т.е. $t^3 + 3t - 14 = 0$, и $t = 2$ — корень.

**2.3.8.** Уравнение $x^3 + ax + b = 0$ имеет три различных вещественных корня. Докажите, что $4a^3 + 27b^2 < 0$.

??? note "Подсказка"
    Три различных вещественных корня $\Leftrightarrow$ $Q < 0$, т.е. $\frac{b^2}{4} + \frac{a^3}{27} < 0$, т.е. $27b^2 + 4a^3 < 0$.
