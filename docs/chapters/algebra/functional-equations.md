# Глава 2.7. Функциональные уравнения

## 2.7.1. Олимпиадный подход

В главе 2.6 мы познакомились с функциональными уравнениями в контексте идемпотентности. Здесь мы сосредоточимся на **олимпиадных** функциональных уравнениях — задачах, требующих найти все функции с заданным свойством.

Стандартный план:
1. Делать умные **подстановки** ($x=0$, $y=0$, $x=y$, $y=x$, $y=-x$, ...).
2. Доказать **инъективность или сюръективность** $f$.
3. Показать **монотонность** или **ограниченность**.
4. Свести к уравнению Коши или подобному.

---

## 2.7.2. Уравнение Коши и его родственники

**$f(x+y) = f(x) + f(y)$** — аддитивная функция.

При условии непрерывности (или монотонности): $f(x) = cx$.

**$f(xy) = f(x) + f(y)$** — логарифмическое.

Замена $x = e^s, y = e^t$: $g(s+t) = g(s) + g(t)$ (уравнение Коши). Решение: $f(x) = c\ln x$.

**$f(xy) = f(x)f(y)$** — мультипликативная функция.

Пусть $f \not\equiv 0$. Подставим $x = y = 1$: $f(1) = f(1)^2$, значит $f(1) = 1$ (или $f(1) = 0$, тогда $f \equiv 0$).

Подставим $y = x$: $f(x^2) = f(x)^2 \geq 0$ — функция неотрицательна на квадратах. При дополнительных условиях: $f(x) = x^c$ или $f(x) = |x|^c$.

## 2.7.3. Олимпиадные задачи: разбор

### Задача 1 (ИМО 2010, задача 1)

**Условие.** Найти все функции $f\colon\mathbb{R}\to\mathbb{R}$, такие что для всех $x, y \in \mathbb{R}$:

$$f(\lfloor x \rfloor y) = f(x)\lfloor f(y) \rfloor$$

**Решение.** Подставим $x \in [0,1)$: $\lfloor x \rfloor = 0$, значит $f(0) = f(x)\lfloor f(y) \rfloor$ для всех $y$.

Если $f$ не тождественно нулевая и не постоянная, то $f(x) \neq 0$ для некоторого $x \in [0,1)$, и $\lfloor f(y) \rfloor = f(0)/f(x)$ — константа. Это означает, что $f(y) \in [c, c+1)$ для некоторого целого $c$. Продолжение анализа даёт $f \equiv 0$ или $f(x) = c$ (константа, при $c = 0$ или $c = 1$).

### Задача 2

**Условие.** Найти все $f\colon\mathbb{Q}\to\mathbb{Q}$, такие что $f(x+y) + f(xy) = f(x)f(y) + 1$.

**Решение.** Подставим $x = y = 0$: $2f(0) = f(0)^2 + 1$, то есть $f(0)^2 - 2f(0) + 1 = 0$, $(f(0)-1)^2 = 0$, $f(0) = 1$.

$x = 0$: $f(y) + f(0) = f(0)f(y) + 1$, то есть $f(y) + 1 = f(y) + 1$ — тривиально.

$y = 1$: $f(x+1) + f(x) = f(x)f(1) + 1$. Пусть $f(1) = c$. Тогда $f(x+1) = (c-1)f(x) + 1$.

Это линейная рекурренция. При $c = 2$: $f(x+1) = f(x) + 1$, то есть $f(n) = n+1$... дальнейший анализ для всех рациональных даёт $f(x) = x+1$ или $f(x) = 1$.

Проверка $f(x) = x+1$: $(x+y+1) + (xy+1) = (x+1)(y+1) + 1$? $x+y+xy+2 = xy+x+y+1+1$. ✓

### Задача 3 (USAMO-стиль)

**Условие.** Найти все строго возрастающие $f\colon\mathbb{R}\to\mathbb{R}$ с $f(f(x)) = x + 2$.

**Решение.** Пусть $g = f \circ f$, тогда $g(x) = x+2$. Заметим: $f(x+2) = f(f(f(x))) = f(x) + 2$.

Значит $f$ — периодичная модуляция: $f(x+2) = f(x) + 2$. Ищем $f$ в виде $f(x) = x + h(x)$, где $h(x+2) = h(x)$. Из строгого возрастания $f$: $h$ ограничена. Из $f(f(x)) = x+2$: $(x + h(x)) + h(x + h(x)) = x + 2$, то есть $h(x) + h(x + h(x)) = 2$.

При $h(x) = 1$ (константа): $f(x) = x + 1$. Проверка: $f(f(x)) = f(x+1) = x+2$. ✓

## 2.7.4. Принципы и стратегии

**Метод подстановок.** Каждая удачная подстановка ограничивает класс решений.

**Инъективность.** Если $f(a) = f(b) \Rightarrow a = b$, то из функционального уравнения можно «сократить» $f$ с обеих сторон.

Для доказательства инъективности: предположим $f(a) = f(b)$ и выведем $a = b$ из уравнения.

**Сюръективность.** Если для любого $z$ существует $x$ с $f(x) = z$, то «правая часть» уравнения может принимать любое значение — и это помогает.

**Чётность/нечётность.** Подставить $x \to -x$, $y \to -y$ и сравнить с исходным.
