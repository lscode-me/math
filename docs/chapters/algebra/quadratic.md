# Глава 4. Квадратные уравнения

## 4.1. Квадратное уравнение: определение

Квадратное уравнение — это уравнение вида:

$$ax^2 + bx + c = 0, \quad a \neq 0$$

Коэффициент $a$ называется **старшим**, $b$ — **средним** (или коэффициентом при $x$), $c$ — **свободным членом**. Условие $a \neq 0$ принципиально: без него уравнение становится линейным.

---

## 4.2. Как геометрия привела к формуле

Квадратные уравнения решали задолго до появления алгебраической записи. Вавилоняне (около 2000 г. до н.э.) решали их **геометрически** — как задачи о площадях.

### Задача вавилонян

> Найти сторону квадрата, если известно, что его площадь плюс сторона равны $\frac{3}{4}$.

На современном языке: $x^2 + x = \frac{3}{4}$.

### Выделение полного квадрата — геометрическая идея

Вавилоняне рассуждали так. Есть квадрат со стороной $x$ (площадь $x^2$) и прямоугольник $x \times 1$ (площадь $x$). Вместе: $x^2 + x$.

Разрежем прямоугольник $x \times 1$ пополам — получим две полоски $x \times \frac{1}{2}$. Приставим их к квадрату: одну справа, другую снизу.

```
      x     ½
  ┌───────┬───┐
  │       │   │
x │  x²   │x/2│
  │       │   │
  ├───────┼───┤
½ │  x/2  │1/4│
  └───────┴───┘
```

Почти получился большой квадрат со стороной $x + \frac{1}{2}$. Не хватает маленького квадратика в углу — $\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}$.

Значит:

$$x^2 + x + \frac{1}{4} = \frac{3}{4} + \frac{1}{4} = 1$$

$$\left(x + \frac{1}{2}\right)^2 = 1$$

$$x + \frac{1}{2} = 1 \quad \Rightarrow \quad x = \frac{1}{2}$$

(Вавилоняне брали только положительный корень — отрицательные числа они не знали.)

Этот приём — **выделение полного квадрата** — лежит в основе всех формул для квадратных уравнений.

---

## 4.3. Выделение полного квадрата: общий случай

Применим ту же идею к произвольному уравнению $ax^2 + bx + c = 0$.

**Шаг 1.** Разделим на $a$ (по принципу из главы 3 — применим одно действие к обеим частям):

$$x^2 + \frac{b}{a}x + \frac{c}{a} = 0$$

**Шаг 2.** Перенесём свободный член:

$$x^2 + \frac{b}{a}x = -\frac{c}{a}$$

**Шаг 3.** Добавим к обеим частям $\left(\frac{b}{2a}\right)^2$, чтобы слева получился полный квадрат:

$$x^2 + \frac{b}{a}x + \frac{b^2}{4a^2} = -\frac{c}{a} + \frac{b^2}{4a^2}$$

$$\left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}$$

**Шаг 4.** Извлечём корень из обеих частей:

$$x + \frac{b}{2a} = \pm\frac{\sqrt{b^2 - 4ac}}{2a}$$

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Это и есть классическая **формула корней квадратного уравнения**.

---

## 4.4. Дискриминант

Выражение под корнем имеет собственное имя:

$$D = b^2 - 4ac$$

Это **дискриминант** (от лат. *discriminare* — различать). Он определяет количество корней:

| Дискриминант | Корни |
|:------------:|-------|
| $D > 0$ | Два различных действительных корня |
| $D = 0$ | Один корень (двойной): $x = -\frac{b}{2a}$ |
| $D < 0$ | Действительных корней нет |

Формула корней через дискриминант:

$$x_{1,2} = \frac{-b \pm \sqrt{D}}{2a}$$

**Пример.** $2x^2 - 7x + 3 = 0$.

$D = (-7)^2 - 4 \cdot 2 \cdot 3 = 49 - 24 = 25$

$x_1 = \frac{7 + 5}{4} = 3, \quad x_2 = \frac{7 - 5}{4} = \frac{1}{2}$

---

## 4.5. Приведённое уравнение ($a = 1$)

Если разделить всё уравнение на $a$, получим **приведённое** квадратное уравнение:

$$x^2 + px + q = 0$$

где $p = \frac{b}{a}$, $q = \frac{c}{a}$.

Формула упрощается:

$$D_1 = p^2 - 4q$$

$$x_{1,2} = \frac{-p \pm \sqrt{p^2 - 4q}}{2}$$

Ещё удобнее записать через **половину** среднего коэффициента. Пусть $p = 2k$ (то есть $k = \frac{p}{2}$):

$$x_{1,2} = -k \pm \sqrt{k^2 - q}$$

Эта формула быстрее в вычислениях, потому что не нужно делить на 2 в конце.

**Пример.** $x^2 - 6x + 5 = 0$.

$p = -6$, $q = 5$, $k = -3$.

$x_{1,2} = 3 \pm \sqrt{9 - 5} = 3 \pm 2$

$x_1 = 5, \quad x_2 = 1$

## 4.6. Теорема Виета

Если $x_1$ и $x_2$ — корни уравнения $ax^2 + bx + c = 0$, то:

$$x_1 + x_2 = -\frac{b}{a}, \quad x_1 \cdot x_2 = \frac{c}{a}$$

Для приведённого уравнения $x^2 + px + q = 0$:

$$x_1 + x_2 = -p, \quad x_1 \cdot x_2 = q$$

### Откуда это следует

Если $x_1$ и $x_2$ — корни, то:

$$a(x - x_1)(x - x_2) = ax^2 - a(x_1 + x_2)x + a \cdot x_1 x_2$$

Сравнивая с $ax^2 + bx + c$:

$$b = -a(x_1 + x_2), \quad c = a \cdot x_1 x_2$$

### Зачем нужна теорема Виета

1. **Подбор корней.** Если коэффициенты целые, можно попробовать подобрать два числа с нужной суммой и произведением — быстрее, чем считать дискриминант.

2. **Проверка.** После нахождения корней по формуле стоит проверить: $x_1 + x_2 = -\frac{b}{a}$?

3. **Составление уравнения.** Если известны корни — уравнение записывается сразу: $x^2 - (x_1+x_2)x + x_1 x_2 = 0$.

**Пример.** $x^2 - 7x + 12 = 0$.

По Виету: сумма корней $= 7$, произведение $= 12$. Подбираем: $3 + 4 = 7$, $3 \times 4 = 12$. Корни: $x_1 = 3$, $x_2 = 4$.

## 4.7. Метод По-Шен Ло

Идея проста и целиком вытекает из теоремы Виета.

Для приведённого уравнения $x^2 + px + q = 0$ теорема Виета даёт:

$$x_1 + x_2 = -p, \qquad x_1 \cdot x_2 = q$$

**Шаг 1. Середина.** Среднее арифметическое корней:

$$x_0 = \frac{x_1 + x_2}{2} = -\frac{p}{2}$$

**Шаг 2.** Запишем корни как $x_1 = x_0 + u$, $x_2 = x_0 - u$ (они симметричны относительно $x_0$). Неизвестна только поправка $u$.

**Шаг 3. Поправка $u$ — из произведения.** Подставим в произведение корней:

$$(x_0 + u)(x_0 - u) = q \quad \Rightarrow \quad x_0^2 - u^2 = q \quad \Rightarrow \quad u = \sqrt{x_0^2 - q}$$

Вот и весь метод:

$$\boxed{x_{1,2} = x_0 \pm u, \qquad x_0 = -\frac{p}{2}, \quad u = \sqrt{x_0^2 - q}}$$

Никаких новых формул не возникло — только Виета и разность квадратов.

!!! note "Po-Shen Loh"
    Этот подход популяризировал в 2019 году **По-Шен Ло** (Po-Shen Loh), профессор университета Карнеги-Меллон и тренер олимпиадной сборной США. Идея не нова — она следует из теоремы Виета, — но Ло предложил элегантную формулировку: вместо запоминания общей формулы, **думать** в терминах «среднее $\pm$ поправка».

---

### Сравнение на примере: $x^2 - 22x + 117 = 0$

#### Классическая формула

$$D = (-22)^2 - 4 \cdot 1 \cdot 117 = 484 - 468 = 16$$

$$\sqrt{D} = 4$$

$$x = \frac{22 \pm 4}{2}$$

$$x_1 = \frac{26}{2} = 13, \quad x_2 = \frac{18}{2} = 9$$

Операции: одно возведение в квадрат ($22^2 = 484$), одно умножение ($4 \times 117 = 468$), вычитание, извлечение корня, два сложения/вычитания, два деления на 2. Промежуточные числа — до **484**.

#### Метод По-Шен Ло

$$x_0 = \frac{22}{2} = 11$$

$$u = \sqrt{11^2 - 117} = \sqrt{121 - 117} = \sqrt{4} = 2$$

$$x_1 = 11 + 2 = 13, \quad x_2 = 11 - 2 = 9$$

Операции: одно деление на 2, одно возведение в квадрат ($11^2 = 121$), вычитание, извлечение корня, два сложения/вычитания. Промежуточные числа — до **121**.

#### Итог

| | Классическая | По-Шен Ло |
|---|---|---|
| Шагов арифметики | 7 | 5 |
| Максимальное промежуточное число | 484 | 121 |
| Деление в конце | да (на 2) | нет |

Метод По-Шен Ло выигрывает в устных и письменных вычислениях: числа меньше, шагов меньше, делить не нужно — мы делим на 2 **сразу**, а не в самом конце.

!!! tip "Для неприведённого уравнения"
    Если $a \neq 1$, достаточно сначала разделить всё уравнение на $a$ — оно станет приведённым, и метод работает как обычно.

## 4.8. Перевёрнутая формула

Стандартная формула:

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Существует альтернативная — **перевёрнутая** — формула:

$$x = \frac{2c}{-b \mp \sqrt{b^2 - 4ac}}$$

(Обратите внимание: знак $\pm$ заменился на $\mp$.)

### Откуда она берётся

**Способ 1: деление уравнения на $x^2$.**

Исходное уравнение $ax^2 + bx + c = 0$ при $x \neq 0$ можно разделить на $x^2$:

$$a + \frac{b}{x} + \frac{c}{x^2} = 0$$

Это квадратное уравнение относительно $\frac{1}{x}$! Сделаем замену $t = \frac{1}{x}$:

$$ct^2 + bt + a = 0$$

Это то же уравнение, но с коэффициентами в обратном порядке: $c$ вместо $a$ и $a$ вместо $c$. Применяем стандартную формулу:

$$t = \frac{-b \pm \sqrt{b^2 - 4ca}}{2c}$$

Дискриминант тот же самый: $b^2 - 4ac$. Возвращаемся к $x = \frac{1}{t}$:

$$x = \frac{1}{t} = \frac{2c}{-b \pm \sqrt{b^2 - 4ac}}$$

Чтобы корни совпали со стандартными, знаки под корнем нужно «перевернуть»: $\pm \to \mp$.

!!! note "Бонус: формула работает и при $a = 0$"
    Стандартная формула $x = \frac{-b \pm \sqrt{D}}{2a}$ требует $a \neq 0$ (иначе деление на ноль). А перевёрнутая формула $x = \frac{2c}{-b \pm \sqrt{b^2 - 4ac}}$ коэффициент $a$ содержит только внутри дискриминанта. При $a = 0$ имеем $D = b^2$, $\sqrt{D} = |b|$, и один из корней:
    
    $$x = \frac{2c}{-b - b} = \frac{2c}{-2b} = -\frac{c}{b}$$
    
    Это в точности решение линейного уравнения $bx + c = 0$. Второй «корень» даёт $\frac{2c}{0}$ — бесконечность, что соответствует тому, что второго корня нет. Таким образом, перевёрнутая формула — более универсальная: она покрывает и квадратный, и линейный случай.

**Способ 2: умножение на сопряжённое.**

Домножим числитель и знаменатель стандартной формулы на **сопряжённое** выражение:

$$x = \frac{-b + \sqrt{D}}{2a} \cdot \frac{-b - \sqrt{D}}{-b - \sqrt{D}} = \frac{(-b)^2 - D}{2a(-b - \sqrt{D})} = \frac{b^2 - (b^2 - 4ac)}{2a(-b - \sqrt{D})} = \frac{4ac}{2a(-b - \sqrt{D})} = \frac{2c}{-b - \sqrt{D}}$$

Аналогично для второго корня:

$$x = \frac{-b - \sqrt{D}}{2a} \quad \rightarrow \quad x = \frac{2c}{-b + \sqrt{D}}$$

Итого два представления каждого корня:

| Корень | Стандартная формула | Перевёрнутая формула |
|--------|--------------------|--------------------|
| $x_1$ | $\frac{-b + \sqrt{D}}{2a}$ | $\frac{2c}{-b - \sqrt{D}}$ |
| $x_2$ | $\frac{-b - \sqrt{D}}{2a}$ | $\frac{2c}{-b + \sqrt{D}}$ |

### Зачем нужна перевёрнутая формула

**Числовая устойчивость.** Если $b > 0$ и $\sqrt{D} \approx b$, то в стандартной формуле для $x_1$:

$$x_1 = \frac{-b + \sqrt{D}}{2a}$$

числитель — разность двух близких чисел. При вычислениях с ограниченной точностью (калькулятор, компьютер) это приводит к **катастрофической потере значащих цифр**.

Перевёрнутая формула для того же корня:

$$x_1 = \frac{2c}{-b - \sqrt{D}}$$

Здесь знаменатель — сумма двух чисел одного знака: ничего не сокращается, точность сохраняется.

**Пример.** $x^2 - 200x + 1 = 0$.

$D = 40000 - 4 = 39996$, $\sqrt{D} \approx 199.99$

Стандартная формула:

$x_1 = \frac{200 - 199.99}{2} = \frac{0.01}{2} = 0.005$ — потеря точности (верный ответ $\approx 0.0050013$)

Перевёрнутая формула:

$x_1 = \frac{2}{200 + 199.99} = \frac{2}{399.99} \approx 0.0050001$ — гораздо точнее.

!!! note "Правило выбора формулы"
    Для каждого корня выбирайте ту формулу (стандартную или перевёрнутую), в которой **нет вычитания близких чисел**:
    
    - Если $b > 0$: для $x_1$ (с $+\sqrt{D}$) лучше перевёрнутая, для $x_2$ (с $-\sqrt{D}$) — стандартная
    - Если $b < 0$: наоборот
    
    Общий рецепт: сначала вычислите тот корень, в формуле которого числитель — **сумма** по модулю, а второй корень найдите через Виета: $x_2 = \frac{c}{a \cdot x_1}$.

## 4.9. Сводка методов

| Метод | Когда удобен |
|-------|-------------|
| Подбор по Виету | Целые коэффициенты, небольшие корни |
| Стандартная формула | Общий случай |
| Формула для приведённого ($a=1$) | После деления на $a$, если $p$ чётное |
| Метод вершины ($x_0 \pm u$) | Когда нужна геометрическая интуиция |
| Перевёрнутая формула | Числовые вычисления, $\|b\|$ и $\sqrt{D}$ близки |
| Выделение полного квадрата | Доказательства, вывод формул |

---

!!! abstract "Резюме главы"
    - Квадратное уравнение $ax^2 + bx + c = 0$ решается **выделением полного квадрата** — приём, восходящий к вавилонской геометрии
    - **Дискриминант** $D = b^2 - 4ac$ определяет количество корней
    - **Теорема Виета**: $x_1 + x_2 = -\frac{b}{a}$, $x_1 x_2 = \frac{c}{a}$ — позволяет подбирать и проверять корни
    - **Метод вершины**: $x_{1,2} = x_0 \pm u$ — геометрический взгляд: центр и полурасстояние
    - **Перевёрнутая формула** $x = \frac{2c}{-b \mp \sqrt{D}}$ — та же формула, но числово устойчивая при близости $|b|$ и $\sqrt{D}$
    - Для каждой задачи есть свой оптимальный метод

**4.4.** Составьте квадратное уравнение с корнями $x_1 = -2$, $x_2 = 7$.

**4.5.** Решите методом вершины: $x^2 - 14x + 33 = 0$.
