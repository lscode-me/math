# Глава 11.2. Суммирование

## 11.2.1. Суммы степеней: формулы Фаулхабера

Обозначим $S_k(n) = 1^k + 2^k + \cdots + n^k$.

| $k$ | Формула |
|-----|---------|
| 0 | $n$ |
| 1 | $\dfrac{n(n+1)}{2}$ |
| 2 | $\dfrac{n(n+1)(2n+1)}{6}$ |
| 3 | $\left(\dfrac{n(n+1)}{2}\right)^2$ |
| 4 | $\dfrac{n(n+1)(2n+1)(3n^2+3n-1)}{30}$ |

**Замечательный факт:** $S_3(n) = S_1(n)^2 = \left(\frac{n(n+1)}{2}\right)^2$ — сумма кубов первых $n$ чисел равна квадрату суммы первых $n$ чисел. Визуальное доказательство: «L-образные гномоны».

### Как вычислить $S_1(n)$: трюк Гаусса

По легенде, маленький Гаусс в школе мгновенно посчитал $1+2+\cdots+100 = 5050$, написав сумму дважды (прямо и задом наперёд) и сложив:

$$1 + 2 + \cdots + (n-1) + n$$
$$n + (n-1) + \cdots + 2 + 1$$

Каждая пара даёт $n+1$, пар ровно $n$: $S_1(n) = \frac{n(n+1)}{2}$.

### Как вычислить $S_2(n)$: метод суммирования по частям

$$S_2(n) = \sum_{k=1}^n k^2$$

Используем тождество $(k+1)^3 - k^3 = 3k^2 + 3k + 1$ и телескопируем:

$$\sum_{k=1}^n [(k+1)^3 - k^3] = (n+1)^3 - 1 = 3S_2(n) + 3S_1(n) + n$$

Откуда: $S_2(n) = \frac{(n+1)^3 - 1 - 3\cdot\frac{n(n+1)}{2} - n}{3} = \frac{n(n+1)(2n+1)}{6}$.

## 11.2.2. Телескопические суммы

**Телескопическая сумма** — сумма, в которой промежуточные слагаемые взаимно уничтожаются:

$$\sum_{k=1}^n (a_{k+1} - a_k) = a_{n+1} - a_1$$

Ключевой приём: представить слагаемое $f(k)$ в виде разности $g(k+1) - g(k)$.

**Пример 1.** $\displaystyle\sum_{k=1}^n \frac{1}{k(k+1)}$.

Заметим: $\frac{1}{k(k+1)} = \frac{1}{k} - \frac{1}{k+1}$.

$$\sum_{k=1}^n \left(\frac{1}{k} - \frac{1}{k+1}\right) = 1 - \frac{1}{n+1} = \frac{n}{n+1}$$

**Пример 2.** $\displaystyle\sum_{k=1}^n k \cdot k!$.

Заметим: $k\cdot k! = (k+1)! - k!$.

$$\sum_{k=1}^n [(k+1)! - k!] = (n+1)! - 1$$

**Пример 3 (тригонометрический).** $\displaystyle\sum_{k=1}^n \sin k$.

Используем: $\sin k = \frac{\cos(k - \frac{1}{2}) - \cos(k + \frac{1}{2})}{2\sin\frac{1}{2}}$.

$$\sum_{k=1}^n \sin k = \frac{\cos\frac{1}{2} - \cos(n+\frac{1}{2})}{2\sin\frac{1}{2}}$$

## 11.2.3. Производящие функции (обзор)

**Производящая функция** последовательности $a_0, a_1, a_2, \ldots$ — это формальный степенной ряд:

$$A(x) = a_0 + a_1 x + a_2 x^2 + \cdots = \sum_{n=0}^\infty a_n x^n$$

«Формальный» означает, что $x$ — не переменная, а символ: мы не подставляем числа, а манипулируем рядом алгебрически.

### Как это работает

**Примеры производящих функций:**

- $\sum x^n = \frac{1}{1-x}$ — геометрическая прогрессия.
- $\sum \binom{n}{k} x^k = (1+x)^n$ — бином Ньютона.
- $\sum F_n x^n = \frac{x}{1-x-x^2}$ — числа Фибоначчи.

**Применение для чисел Каталана:** $C(x) = \sum C_n x^n$ удовлетворяет $C(x) = 1 + x C(x)^2$ (из рекурренции). Это квадратное уравнение: $x C^2 - C + 1 = 0$, откуда $C(x) = \frac{1 - \sqrt{1-4x}}{2x}$, и разложение в ряд даёт $C_n = \frac{1}{n+1}\binom{2n}{n}$.

### Почему это полезно

Производящие функции превращают **суммирование в алгебру**: умножение рядов соответствует свёртке последовательностей, деление — обращению, взятие производной — сдвигу. Задача «найти формулу для $a_n$» превращается в «найти коэффициент $x^n$ в функции $A(x)$».

## 11.2.4. Формула Эйлера–Маклорена (обзор)

Формула Эйлера–Маклорена связывает сумму со значениями функции на концах:

$$\sum_{k=0}^n f(k) = \int_0^n f(x)\,dx + \frac{f(0)+f(n)}{2} + \sum_{j=1}^p \frac{B_{2j}}{(2j)!}\left[f^{(2j-1)}(n) - f^{(2j-1)}(0)\right] + R_p$$

где $B_{2j}$ — числа Бернулли, $R_p$ — остаточный член.

**Смысл:** сумму можно приближать интегралом с поправками. Это один из ключевых инструментов аналитической теории чисел (оценка числа простых, формула Стирлинга).

**Формула Стирлинга** как следствие:

$$n! \approx \sqrt{2\pi n}\left(\frac{n}{e}\right)^n$$

Это асимптотика, получаемая применением формулы Эйлера–Маклорена к $\ln(n!) = \sum_{k=1}^n \ln k$.

## Итоги главы

- **Суммы степеней**: $S_k(n)$ — полиномы степени $k+1$; $S_3(n) = S_1(n)^2$.
- **Телескопирование**: $f(k) = g(k+1) - g(k)$ → $\sum f(k) = g(n+1) - g(1)$.
- **Производящие функции**: степенной ряд $A(x) = \sum a_n x^n$ превращает рекурренции в уравнения.
- **Формула Эйлера–Маклорена**: мост между суммой и интегралом; даёт формулу Стирлинга.
