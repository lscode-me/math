# Глава 10.3. Суммы Рамануджана

## 10.3.1. Определение и первые примеры

**Сумма Рамануджана** — это экспоненциальная сумма, «просматривающая» только взаимно простые остатки по модулю $q$:

$$c_q(n) = \sum_{\substack{a=1 \\ \gcd(a,q)=1}}^{q} e^{2\pi i a n / q}$$

Иными словами: мы суммируем $e^{2\pi i a n / q}$ по всем $a \in \{1, \ldots, q\}$ с условием $\gcd(a, q) = 1$.

**Историческая справка.** Сриниваса Рамануджан ввёл эти суммы в 1918 году в статье «On certain trigonometrical sums». Несмотря на элементарный вид, они оказались ключевым инструментом аддитивной теории чисел.

**Простейшие случаи:**

- $q = 1$: единственный член при $a = 1$, $\gcd(1,1) = 1$. Поэтому $c_1(n) = e^{2\pi i n} = 1$.

- $q = 2$: $\gcd(1,2) = 1$, $\gcd(2,2) = 2$. Только $a=1$: $c_2(n) = e^{\pi i n} = (-1)^n$.

- $q = 3$: $a \in \{1, 2\}$, оба взаимно просты с 3. $c_3(n) = e^{2\pi i n/3} + e^{4\pi i n/3}$.
  - При $n \equiv 0 \pmod 3$: оба слагаемых равны 1, сумма = $2$.
  - При $n \not\equiv 0 \pmod 3$: это примитивные корни из 1, сумма = $-1$.

**Вычислительная формула.** Используя функцию Мёбиуса $\mu$ и функцию Эйлера $\varphi$:

$$c_q(n) = \mu\!\left(\frac{q}{\gcd(q,n)}\right) \frac{\varphi(q)}{\varphi\!\left(\frac{q}{\gcd(q,n)}\right)}$$

Это позволяет вычислять $c_q(n)$ чисто арифметически.

## 10.3.2. Связь с функцией Эйлера и мультипликативность

**Важный частный случай $n = 0$:**

$$c_q(0) = \sum_{\substack{a=1 \\ \gcd(a,q)=1}}^{q} 1 = \varphi(q)$$

Это в точности функция Эйлера $\varphi(q)$ — число взаимно простых с $q$ остатков.

**Мультипликативность по $q$.** Если $\gcd(q_1, q_2) = 1$, то:

$$c_{q_1 q_2}(n) = c_{q_1}(n) \cdot c_{q_2}(n)$$

Это означает, что $c_q(n)$ как функция от $q$ — **мультипликативная функция** (при фиксированном $n$). Благодаря этому достаточно вычислить $c_{p^k}(n)$ для простых степеней, а значения для составных $q$ получаются перемножением.

**Значения на простых степенях.** Пусть $p$ — простое число:

$$c_{p^k}(n) = \begin{cases} \varphi(p^k) = p^k - p^{k-1} & \text{если } p^k \mid n, \\ -p^{k-1} & \text{если } p^{k-1} \mid n,\ p^k \nmid n, \\ 0 & \text{иначе.} \end{cases}$$

## 10.3.3. Разложения Рамануджана

Главная идея: **любую «разумную» арифметическую функцию** можно разложить в ряд по суммам Рамануджана:

$$f(n) = \sum_{q=1}^{\infty} a_q \, c_q(n)$$

Это аналог ряда Фурье, но «на числовой прямой $\mathbb{Z}$» с «частотами» $q$.

**Коэффициент разложения** определяется формулой:

$$a_q = \lim_{N \to \infty} \frac{1}{N} \sum_{n=1}^{N} f(n) \overline{c_q(n)}$$

### Разложение функции $d(n)$ (число делителей)

$$d(n) = \sum_{q=1}^{\infty} \frac{\log q}{q} \, c_q(n) + \gamma \quad \text{(в смысле Чезаро)}$$

где $\gamma$ — постоянная Эйлера–Маскерони.

### Разложение функции $\sigma(n)$ (сумма делителей)

$$\frac{\sigma(n)}{n} = \frac{\pi^2}{6} \sum_{q=1}^{\infty} \frac{c_q(n)}{\varphi(q) q}$$

Эти формулы выглядят как «теоремы типа Фурье», где место «гармоник» $e^{i n \omega}$ заняли $c_q(n)$.

## 10.3.4. Связь с рядами Фурье по модулю

Пусть $f\colon \mathbb{Z} \to \mathbb{C}$ — **периодическая с периодом $q$**. Тогда её ряд Фурье конечен:

$$f(n) = \sum_{a=0}^{q-1} \hat{f}(a) \, e^{2\pi i a n / q}$$

Если $f$ зависит только от $\gcd(n, q)$ (функция зависит лишь от НОД), то её разложение Фурье выражается через суммы Рамануджана. Это наблюдение лежит в основе **метода Харди–Литтлвуда–Рамануджана** в аддитивной теории чисел.

**Ортогональность.** Суммы Рамануджана удовлетворяют «условию ортогональности»:

$$\sum_{n=1}^{q} c_q(n) \overline{c_{q'}(n)} = \varphi(q) \cdot [q = q']$$

(в смысле суммирования по одному периоду), что оправдывает аналогию с рядом Фурье.

## 10.3.5. Круговой метод и приложения

**Круговой метод Харди–Литтлвуда (1920).** Для оценки числа представлений $n$ в виде суммы $k$ простых чисел (гипотеза Гольдбаха, задача Варинга) используется интеграл:

$$r_k(n) = \int_0^1 S(\alpha)^k e^{-2\pi i n \alpha} \, d\alpha, \quad S(\alpha) = \sum_{p \leq N} e^{2\pi i p \alpha}$$

«Главные дуги» интеграла находятся вблизи рациональных точек $a/q$ с малым $q$. Вклад главных дуг выражается через суммы Рамануджана $c_q(n)$, а «минорные дуги» малы.

**Задача Варинга.** Представление каждого натурального числа в виде суммы $k$-х степеней: $n = x_1^k + x_2^k + \cdots + x_s^k$. Круговой метод даёт асимптотику числа представлений, главный член которой — «сингулярная серия»:

$$\mathfrak{S}(n) = \sum_{q=1}^{\infty} \frac{1}{\varphi(q)^s} \sum_{\substack{a=1 \\ \gcd(a,q)=1}}^{q} e^{2\pi i a n / q} = \sum_{q=1}^{\infty} \frac{c_q(n)}{\varphi(q)^s}$$

**Гипотеза Гольдбаха** (нерешённая). Каждое чётное $n \geq 4$ есть сумма двух простых. Тернарная гипотеза Гольдбаха ($n \geq 7$ нечётное — сумма трёх простых) доказана Хелфготтом в 2013 году с помощью кругового метода.

## 10.3.6. Числовые примеры

**Пример 1.** Вычислим $c_6(n)$.

$\gcd(a, 6) = 1$ при $a \in \{1, 5\}$. Значит:
$$c_6(n) = e^{2\pi i n/6} + e^{10\pi i n/6} = e^{\pi i n/3} + e^{5\pi i n/3}$$

Через мультипликативность: $c_6(n) = c_2(n) \cdot c_3(n) = (-1)^n \cdot c_3(n)$.

| $n \bmod 6$ | $c_2(n)$ | $c_3(n)$ | $c_6(n)$ |
|:-----------:|:--------:|:--------:|:--------:|
| 0 | 1 | 2 | 2 |
| 1 | −1 | −1 | 1 |
| 2 | 1 | −1 | −1 |
| 3 | −1 | 2 | −2 |
| 4 | 1 | −1 | −1 |
| 5 | −1 | −1 | 1 |

**Пример 2.** Проверим формулу $c_p(n) = -1$ для простого $p \nmid n$.

$c_5(1) = e^{2\pi i/5} + e^{4\pi i/5} + e^{6\pi i/5} + e^{8\pi i/5}$ — сумма всех примитивных корней 5-й степени из 1. Они суть все корни уравнения $z^5 = 1$ кроме $z = 1$, поэтому сумма = $-1$. ✓

## Итоги главы

- **Суммы Рамануджана** $c_q(n)$ — тригонометрические суммы по взаимно простым остаткам; вещественны и целочисленны.
- **Мультипликативность**: $c_{q_1 q_2}(n) = c_{q_1}(n) c_{q_2}(n)$ при $\gcd(q_1, q_2) = 1$.
- Формула: $c_q(n) = \mu\!\left(\frac{q}{\gcd(q,n)}\right)\dfrac{\varphi(q)}{\varphi(q/\gcd(q,n))}$.
- **Разложения Рамануджана** — аналог ряда Фурье для арифметических функций.
- **Круговой метод**: суммы Рамануджана — строительный блок главных дуг в задачах Варинга и Гольдбаха.
