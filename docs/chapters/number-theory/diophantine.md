# Глава 10.2. Диофантовы уравнения

## 10.2.1. Что такое диофантово уравнение

**Диофантово уравнение** — это уравнение (или система уравнений), в котором ищутся **целочисленные** или натуральные решения. Названо в честь Диофанта Александрийского (III в. н.э.), чья «Арифметика» — первый известный трактат по такого рода задачам.

В отличие от вещественных уравнений, диофантовы могут иметь:
- **Бесконечно много** решений (например, $x + y = 5$).
- **Конечное число** решений.
- **Ни одного** решения (например, $x^2 + y^2 = 3$).

---

## 10.2.2. Линейные диофантовы уравнения

Уравнение $ax + by = c$ (целые коэффициенты, целые решения).

!!! important "Критерий разрешимости"
    Уравнение $ax + by = c$ имеет целочисленные решения тогда и только тогда, когда $\gcd(a, b) \mid c$.

**Доказательство.** Если $d = \gcd(a, b)$, то любое значение $ax + by$ кратно $d$ (так как $a$ и $b$ кратны $d$). Значит, если $d \nmid c$, решений нет. Если $d \mid c$, то, разделив на $d$, получаем $a'x + b'y = c'$ с $\gcd(a', b') = 1$, и расширенный алгоритм Евклида находит одно частное решение $(x_0, y_0)$.

**Общее решение.** Если $(x_0, y_0)$ — одно решение, то все решения:

$$x = x_0 + \frac{b}{d}t, \quad y = y_0 - \frac{a}{d}t, \quad t \in \mathbb{Z}$$

**Пример.** Решить $3x + 5y = 1$.

Алгоритм Евклида: $5 = 1\cdot3 + 2$, $3 = 1\cdot2 + 1$, $2 = 2\cdot1$. Обратный ход: $1 = 3 - 1\cdot2 = 3 - 1\cdot(5-3) = 2\cdot3 - 5$. Значит $x_0 = 2$, $y_0 = -1$.

Проверка: $3\cdot2 + 5\cdot(-1) = 1$. ✓

Общее решение: $x = 2 + 5t$, $y = -1 - 3t$.

## 10.2.3. Пифагоровы тройки

**Пифагорова тройка** — набор натуральных чисел $(a, b, c)$ с $a^2 + b^2 = c^2$.

Первые примеры: $(3,4,5)$, $(5,12,13)$, $(8,15,17)$, $(7,24,25)$.

### Полная параметризация

!!! important "Теорема"
    Все **примитивные** пифагоровы тройки (с $\gcd(a,b,c)=1$, $a$ нечётное) имеют вид:
    
    $$a = m^2 - n^2, \quad b = 2mn, \quad c = m^2 + n^2$$
    
    где $m > n > 0$, $\gcd(m,n) = 1$, $m \not\equiv n \pmod 2$.

**Проверка.** $a^2 + b^2 = (m^2-n^2)^2 + (2mn)^2 = m^4 - 2m^2n^2 + n^4 + 4m^2n^2 = m^4 + 2m^2n^2 + n^4 = (m^2+n^2)^2 = c^2$.

**Примеры.** $m=2, n=1$: $(3, 4, 5)$. $m=3, n=2$: $(5, 12, 13)$. $m=4, n=1$: $(15, 8, 17)$.

Все пифагоровы тройки получаются умножением примитивных на натуральное число $k$.

**Связь с гауссовыми целыми.** Разложение $c^2 = a^2 + b^2 = (a+bi)(a-bi)$ в кольце гауссовых целых $\mathbb{Z}[i]$ даёт элегантное объяснение параметризации.

## 10.2.4. Великая теорема Ферма

Пьер де Ферма в 1637 г. записал на полях книги:

> «Невозможно разложить куб на два куба, биквадрат на два биквадрата и вообще никакую степень, большую квадрата, на две степени с тем же показателем.»

И добавил: «Я открыл поистине чудесное доказательство этого, но поля книги слишком узки для него».

!!! important "Великая теорема Ферма"
    Уравнение $x^n + y^n = z^n$ не имеет решений в натуральных числах при $n \geq 3$.

Теорема была полностью доказана лишь в **1995 году** Эндрю Уайлсом (после 8 лет тайной работы). Доказательство занимает более 100 страниц и использует теорию эллиптических кривых, модулярные формы и теорему Сингера–Вейля.

**Исторические вехи:**
- $n = 4$: Ферма (1670) — метод бесконечного спуска.
- $n = 3$: Эйлер (1770) — с некоторыми пробелами.
- $n = 5$: Лежандр и Дирихле (1825).
- $n = 7$: Ламе (1839).
- Все простые $p < 100$: Куммер (1850-е) — идеальные числа.
- Все $n \leq 4\,000\,000$: компьютерная проверка (XX в.).
- Все $n$: Уайлс (1995).

Простое $p$ называется **регулярным**, если оно не делит числители чисел Бернулли $B_2, B_4, \ldots, B_{p-3}$. Куммер доказал теорему для регулярных простых.

## 10.2.5. Уравнение Пелля

**Уравнение Пелля:** $x^2 - Dy^2 = 1$, где $D > 0$ — не является полным квадратом.

Примеры: $x^2 - 2y^2 = 1$, $x^2 - 3y^2 = 1$.

### Связь с непрерывными дробями

Если $\sqrt{D} = [a_0; \overline{a_1, a_2, \ldots, a_k}]$ — периодическая непрерывная дробь, то решение уравнения Пелля даётся **подходящими дробями** (convergents).

**Пример.** Решить $x^2 - 2y^2 = 1$.

$\sqrt{2} = 1 + (\sqrt{2}-1) = 1 + \frac{1}{1 + \frac{1}{\sqrt{2}+1}} = [1; \overline{2}]$.

Подходящие дроби: $\frac{1}{1}, \frac{3}{2}, \frac{7}{5}, \frac{17}{12}, \ldots$

Проверяем $p/q$: $1^2 - 2\cdot1^2 = -1$. $3^2 - 2\cdot2^2 = 9-8 = 1$. Первое решение: $(3, 2)$.

Общее решение: $(x_n, y_n)$ даётся рекуррентно: $x_{n+1} = x_1 x_n + D y_1 y_n$, $y_{n+1} = y_1 x_n + x_1 y_n$, или через степени: $(x_n + y_n\sqrt{D}) = (x_1 + y_1\sqrt{D})^n$.

**Применение.** В средние века уравнение Пелля встречалось в задачах «о скоте Архимеда» (и схожих): требовалось найти огромные натуральные числа, удовлетворяющие определённым условиям, — решение сводится к уравнению Пелля с астрономически большими ответами (числа с сотнями цифр).

!!! abstract "Резюме главы"
    - **Линейные уравнения** $ax+by=c$: разрешимы ↔ $\gcd(a,b) \mid c$; общее решение через алгоритм Евклида
    - **Пифагоровы тройки**: все примитивные — $(m^2-n^2, 2mn, m^2+n^2)$
    - **Теорема Ферма**: $x^n+y^n=z^n$ неразрешима при $n \geq 3$; доказана Уайлсом в 1995 г.
    - **Уравнение Пелля** $x^2 - Dy^2 = 1$: решается через непрерывные дроби $\sqrt{D}$
