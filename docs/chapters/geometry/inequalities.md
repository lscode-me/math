# Глава 8.5. Геометрические неравенства

## 8.5.1. Неравенство треугольника

**Неравенство треугольника:** для любых трёх точек $A, B, C$:

$$|AC| \leq |AB| + |BC|$$

с равенством тогда и только тогда, когда $B$ лежит на отрезке $AC$.

Это не просто «свойство треугольника» — это **аксиома метрики**: любое расстояние, удовлетворяющее неравенству треугольника, является корректной метрикой (им определяются абстрактные метрические пространства).

### Следствия

**Сторона треугольника.** Каждая сторона строго меньше суммы двух других и строго больше их разности:

$$|a - b| < c < a + b$$

**Медиана треугольника.** Для медианы $m_c$, соединяющей вершину $C$ с серединой $AB$:

$$\frac{|a - b|}{2} < m_c < \frac{a + b}{2}$$

### Обобщение: неравенство треугольника для векторов

$$|\vec{u} + \vec{v}| \leq |\vec{u}| + |\vec{v}|$$

Это эквивалентно неравенству Коши–Буняковского: $(\vec{u} \cdot \vec{v})^2 \leq |\vec{u}|^2 |\vec{v}|^2$.

## 8.5.2. Изопериметрическое неравенство

**Вопрос.** Среди всех замкнутых кривых с данным периметром $L$, какая ограничивает наибольшую площадь?

!!! important "Изопериметрическое неравенство"
    Для любой замкнутой кривой длины $L$, ограничивающей площадь $S$:
    
    $$4\pi S \leq L^2$$
    
    Равенство достигается только для **окружности**.

Для окружности: $L = 2\pi r$, $S = \pi r^2$, $4\pi \cdot \pi r^2 = 4\pi^2 r^2 = (2\pi r)^2 = L^2$. Равенство! ✓

**Для многоугольников.** Среди всех $n$-угольников с данным периметром наибольшую площадь имеет **правильный $n$-угольник**.

Частный случай ($n=3$): среди треугольников с данным периметром наибольшую площадь имеет **равносторонний** (формула Герона: при фиксированном $s$ максимум $\sqrt{s(s-a)(s-b)(s-c)}$ достигается при $a = b = c$).

**Доказательство (для многоугольников, два шага):**

Шаг 1. Многоугольник с максимальной площадью при данном периметре должен быть **выпуклым** (вогнутость можно «откинуть», увеличив площадь, не меняя периметр).

Шаг 2. Выпуклый многоугольник с максимальной площадью **вписан в окружность** (если сторона $AB$ не является хордой описанной окружности, можно переместить вершины, увеличив площадь).

## 8.5.3. Неравенство Птолемея

!!! important "Неравенство Птолемея"
    Для любых четырёх точек $A, B, C, D$ на плоскости:
    
    $$AC \cdot BD \leq AB \cdot CD + AD \cdot BC$$
    
    Равенство достигается тогда и только тогда, когда $A, B, C, D$ лежат на одной окружности (в этом порядке).

**Теорема Птолемея** — это случай равенства: для вписанного четырёхугольника $AC \cdot BD = AB \cdot CD + AD \cdot BC$.

Неравенство Птолемея — мощный инструмент: оно позволяет оценивать суммы произведений диагоналей.

## 8.5.4. Другие важные геометрические неравенства

### Неравенство для углов треугольника

Для углов $A, B, C$ треугольника:

$$\sin A + \sin B + \sin C \leq \frac{3\sqrt{3}}{2}$$

Равенство — в равностороннем треугольнике. Следует из выпуклости $\sin$ на $(0, \pi)$ и неравенства Йенсена.

### Неравенство Эрдёша–Мордела

Для точки $P$ внутри треугольника $ABC$ с расстояниями $d_a, d_b, d_c$ до сторон и расстояниями $\rho_a, \rho_b, \rho_c$ до вершин:

$$\rho_a + \rho_b + \rho_c \geq 2(d_a + d_b + d_c)$$

Это глубокое неравенство, предложенное Эрдёшем в 1935 г. и первоначально кажущееся неочевидным.

## Итоги главы

- **Неравенство треугольника**: $|AC| \leq |AB| + |BC|$; основа метрических пространств.
- **Изопериметрическое неравенство**: $4\pi S \leq L^2$; максимальная площадь при данном периметре — у круга.
- **Неравенство Птолемея**: $AC \cdot BD \leq AB \cdot CD + AD \cdot BC$; равенство — для вписанного четырёхугольника.
