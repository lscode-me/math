# Глава 8.9. Исследование площади треугольника

## 8.9.1. Формула Герона и программная реализация

Формула Герона (§8.2.1) позволяет вычислить площадь любого треугольника по трём сторонам:

$$S = \sqrt{s(s-a)(s-b)(s-c)}, \quad s = \frac{a+b+c}{2}$$

```python
import math

def heron(a, b, c):
    s = (a + b + c) / 2
    area_sq = s * (s - a) * (s - b) * (s - c)
    if area_sq < 0:
        return 0  # вырожденный треугольник
    return math.sqrt(area_sq)
```

**Проверка треугольного неравенства.** Три стороны образуют треугольник тогда и только тогда, когда каждая строго меньше суммы двух других: $a + b > c$, $a + c > b$, $b + c > a$.

## 8.9.2. Равнобедренные треугольники: зависимость площади от параметра

Рассмотрим равнобедренный треугольник с $a = b$ и $c = a \cdot x$ (параметр $x$ — отношение основания к боковой стороне).

$$s = \frac{a + a + ax}{2} = \frac{a(2+x)}{2}$$

$$S = \sqrt{\frac{a(2+x)}{2}\cdot\frac{a(2-x)}{2}\cdot\frac{ax}{2}\cdot\frac{ax}{2}} = \frac{a^2 x}{4}\sqrt{4-x^2}$$

**Анализ:** $S(x) = \frac{a^2}{4}x\sqrt{4-x^2}$ на допустимом промежутке $0 < x < 2$ (треугольное неравенство).

**Максимум площади.** Найдём $x$, максимизирующее $f(x) = x^2(4-x^2) = 4x^2 - x^4$.

$f'(x) = 8x - 4x^3 = 4x(2 - x^2) = 0 \Rightarrow x = \sqrt{2}$.

При $x = \sqrt{2}$: $c = a\sqrt{2}$. Это равнобедренный прямоугольный треугольник (катеты $a$, гипотенуза $a\sqrt{2}$)!

**Вывод:** среди равнобедренных треугольников с фиксированным $a = b$ максимальная площадь у прямоугольного.

## 8.9.3. Когда два значения $x$ дают одинаковую площадь

Уравнение $S(x) = S(x_0)$ при фиксированном $a$ и переменном $x$:

$$x\sqrt{4-x^2} = x_0\sqrt{4-x_0^2}$$

Обозначим $f(x) = x\sqrt{4-x^2} = \sqrt{x^2(4-x^2)}$. Это чётная функция (по $x^2$) с максимумом при $x = \sqrt{2}$.

Уравнение $f(x) = C$ имеет два решения при $C < f(\sqrt{2})$: одно на $(0, \sqrt{2})$, другое на $(\sqrt{2}, 2)$. Эти два треугольника имеют одинаковую площадь, но разные пропорции.

**Пример.** $x_1 = 1$ (равносторонний: $c = a$): $f(1) = \sqrt{3}$.

Второе решение: $x_2\sqrt{4-x_2^2} = \sqrt{3}$. Пусть $t = x_2^2$: $t(4-t) = 3$, то есть $t^2 - 4t + 3 = 0$, $t = 1$ или $t = 3$. Значит $x_2 = \sqrt{3}$.

Треугольник с $x_2 = \sqrt{3}$ (основание $a\sqrt{3}$, бока $a$) имеет ту же площадь, что равносторонний.

## 8.9.4. Пифагоровы тройки как треугольники

**Пифагорова тройка** $(a, b, c)$ задаёт прямоугольный треугольник с площадью $S = ab/2$.

Параметризация (из §10.2.3): $a = m^2-n^2$, $b = 2mn$, $c = m^2+n^2$.

$$S = \frac{ab}{2} = \frac{(m^2-n^2)\cdot 2mn}{2} = mn(m^2-n^2) = mn(m-n)(m+n)$$

**Задача.** Найти все целочисленные треугольники $(a, b, c)$ с площадью, равной периметру.

$S = p$: $\sqrt{s(s-a)(s-b)(s-c)} = a+b+c = 2s$.

$s(s-a)(s-b)(s-c) = 4s^2$, то есть $(s-a)(s-b)(s-c) = 4s$.

Перебор при фиксированных периметрах (метод Эйлера) даёт конечный список: $(5,12,13)$, $(6,8,10)$, $(5,5,6)$, $(5,5,8)$ и $(9,10,17)$.

!!! abstract "Резюме главы"
    - Формула Герона программно: простая реализация, важна проверка вырожденности
    - Равнобедренные треугольники с фиксированными боковыми сторонами: максимальная площадь у прямоугольного
    - Два треугольника с одинаковой площадью при данных боках: параметрически решается через квадратное уравнение
    - Площадь пифагоровой тройки: $S = mn(m-n)(m+n)$
