# Глава 8.9. Равнобедренный треугольник, одинаковые площади и пифагоровы тройки

> Одна загадка из школьного учебника, если её хорошенько раскрутить, ведёт нас от элементарной планиметрии к параметрическим формулам, симметриям и старейшим объектам теории чисел — пифагоровым тройкам.

## 8.9.1. Загадка двух треугольников

Возьмём два равнобедренных треугольника с одинаковыми боковыми сторонами $a = 10$, но разными основаниями:

- **Треугольник $T_1$**: стороны $10,\ 10,\ 16$.
- **Треугольник $T_2$**: стороны $10,\ 10,\ 12$.

Какой из них имеет большую площадь? Естественная интуиция: длиннее основание — больше «развалистость» — наверное, больше площадь? Или, наоборот, длиннее основание — площе треугольник — меньше высота — меньше площадь?

Проверим. Для равнобедренного треугольника со сторонами $a, a, c$ высота из вершины к основанию делит основание пополам и образует с боковой стороной прямоугольный треугольник с катетами $h$ и $c/2$ и гипотенузой $a$:

$$h = \sqrt{a^2 - \left(\frac{c}{2}\right)^2}, \qquad S = \frac{1}{2}\,c\,h.$$

Подставим:

| Треугольник | Половина основания $c/2$ | Высота $h$ | Площадь $S = \tfrac{1}{2}ch$ |
|---|---|---|---|
| $T_1\colon 10,10,16$ | $8$ | $\sqrt{100 - 64} = 6$ | $\tfrac{1}{2}\cdot 16\cdot 6 = 48$ |
| $T_2\colon 10,10,12$ | $6$ | $\sqrt{100 - 36} = 8$ | $\tfrac{1}{2}\cdot 12\cdot 8 = 48$ |

**Площади одинаковы.** Оба треугольника имеют площадь ровно $48$.

Это совпадение? Случайность? Или за ним прячется закономерность?

!!! note "Что в этом удивительного"
    - Треугольники не равны (даже не подобны): у одного основание $16$, у другого $12$.
    - Совпадение площадей не следует ни из какой «школьной» формулы.
    - Если посмотреть на таблицу выше внимательно, видно, что в обоих случаях фигурируют числа $6, 8, 10$ — узнаваемая **пифагорова тройка**. Но почему именно она?

В этой главе мы постепенно раскрутим эту загадку:

1. Выпишем формулу площади равнобедренного треугольника как функцию его «формы».
2. Избавимся от масштаба, введя безразмерный параметр $x$.
3. Найдём максимум площади и пограничные случаи.
4. Обнаружим симметрию $x_1^2 + x_2^2 = 4$, объясняющую совпадение.
5. Увидим, что эта симметрия — лицо пифагоровых троек, выглядывающих из задачи.

## 8.9.2. Площадь равнобедренного треугольника через высоту

Рассмотрим произвольный равнобедренный треугольник $ABC$ с $AB = AC = a$ и основанием $BC = c$.

```
            A
           /|\
          / | \
       a /  |h \ a
        /   |   \
       /    |    \
      B-----+-----C
       c/2     c/2
```

**Высота к основанию.** Опустим из вершины $A$ перпендикуляр $AH$ на $BC$. В равнобедренном треугольнике высота из вершины при равных сторонах одновременно является медианой и биссектрисой — поэтому $H$ — середина $BC$, и $BH = HC = c/2$.

**Теорема Пифагора.** В прямоугольном треугольнике $ABH$ катеты — это $h$ и $c/2$, гипотенуза — это $a$:

$$a^2 = h^2 + \left(\frac{c}{2}\right)^2 \quad\Longrightarrow\quad h = \sqrt{a^2 - \frac{c^2}{4}}.$$

**Формула площади.** Площадь треугольника — половина основания на высоту:

$$\boxed{\; S = \frac{1}{2}\,c\,h = \frac{c}{2}\sqrt{a^2 - \frac{c^2}{4}} \;}$$

**Условие существования.** Чтобы корень имел смысл, нужно $a^2 > c^2/4$, то есть $c < 2a$ — это в точности треугольное неравенство для равнобедренного случая ($a + a > c$).

**Применение к загадке.** Подставим в формулу значения из §8.9.1:

- $T_1\colon a=10,\ c=16$: $h=\sqrt{100-64}=6$, $S = 8\cdot 6 = 48$.
- $T_2\colon a=10,\ c=12$: $h=\sqrt{100-36}=8$, $S = 6\cdot 8 = 48$.

Совпадение площадей подтверждается, но пока выглядит как численное чудо. Нужна формула, в которой это чудо станет видимым.

## 8.9.3. Проверка формулой Герона

В §8.2.1 мы уже видели **формулу Герона**, выражающую площадь произвольного треугольника через три стороны:

$$S = \sqrt{s(s-a)(s-b)(s-c)}, \qquad s = \frac{a+b+c}{2}.$$

Для нашей задачи удобно проверить ответ программно:

```python
import math

def heron(a, b, c):
    """Площадь треугольника по трём сторонам.
    Возвращает 0 для вырожденного треугольника."""
    s = (a + b + c) / 2
    area_sq = s * (s - a) * (s - b) * (s - c)
    if area_sq < 0:
        return 0.0
    return math.sqrt(area_sq)

print(heron(10, 10, 16))  # 48.0
print(heron(10, 10, 12))  # 48.0
```

Оба вызова дают `48.0`. Совпадение реально, а не результат особого выбора формулы.

!!! note "Подвох вычислительной устойчивости"
    Для «почти вырожденных» треугольников (когда одна сторона очень близка к сумме двух других) формула Герона теряет точность из-за вычитания близких чисел. На таких случаях лучше использовать устойчивую версию Кахана — см. §8.2.1.

В равнобедренном случае проверим, что формула Герона эквивалентна нашей. Подставим $b=a$:

$$s = \frac{2a + c}{2}, \quad s - a = \frac{c}{2}, \quad s - b = \frac{c}{2}, \quad s - c = \frac{2a-c}{2}.$$

$$S^2 = \frac{(2a+c)(2a-c)}{4} \cdot \left(\frac{c}{2}\right)^2 = \frac{c^2(4a^2 - c^2)}{16},$$

$$S = \frac{c}{4}\sqrt{4a^2 - c^2} = \frac{c}{2}\sqrt{a^2 - \frac{c^2}{4}}.$$

Это то же самое выражение, к которому мы пришли через высоту. Хорошо, формула надёжна. Теперь — главный шаг.

## 8.9.4. Безразмерный параметр: разделяем масштаб и форму

В формуле $S = \tfrac{c}{4}\sqrt{4a^2 - c^2}$ участвуют **два** параметра: $a$ и $c$. Но один из них — это просто «размер» треугольника, а второй — его «форма». Если умножить и $a$, и $c$ на одно и то же число $k$, получится подобный треугольник, и площадь умножится на $k^2$. Содержательная информация — в **отношении** сторон.

Введём **безразмерный параметр** $x$, равный отношению основания к боковой стороне:

$$x = \frac{c}{a}, \qquad c = a\,x.$$

Подставим в формулу площади:

$$S = \frac{ax}{4}\sqrt{4a^2 - a^2 x^2} = \frac{ax}{4}\cdot a\sqrt{4 - x^2} = \frac{a^2}{4}\,x\sqrt{4 - x^2}.$$

$$\boxed{\; S(x) = \frac{a^2}{4}\,x\sqrt{4 - x^2}, \qquad 0 < x < 2. \;}$$

Это и есть «формула формы». Множитель $a^2/4$ отвечает за масштаб (площадь — двумерная величина), а вся информация о форме упакована в функцию $f(x) = x\sqrt{4-x^2}$.

!!! info "Зачем нормализовать"
    Нормализация (избавление от масштаба) — стандартный приём, превращающий двупараметрическую задачу в однопараметрическую. Кроме экономии переменных, он делает зримой геометрию: одна функция $f(x)$ описывает **все** равнобедренные треугольники с фиксированными боковыми сторонами.

**Что значит $x$:**

| Значение $x$ | Геометрия треугольника |
|---|---|
| $x \to 0$ | Основание стягивается в точку, треугольник вырождается в «иголку» |
| $x = 1$ | Равносторонний: все три стороны равны $a$ |
| $x = \sqrt{2} \approx 1.414$ | Равнобедренный прямоугольный (катеты $a$, гипотенуза $a\sqrt{2}$) |
| $x \to 2$ | Основание $\to 2a$: треугольник «расплющивается» в отрезок |

## 8.9.5. Первые наблюдения: пределы и максимум

Имея явную формулу $S(x) = \tfrac{a^2}{4}\,x\sqrt{4-x^2}$, мы можем сразу извлечь несколько фактов.

### Пограничные случаи

**$x \to 0$.** Тогда $\sqrt{4-x^2} \to 2$, а множитель $x$ стремится к нулю. Площадь обращается в ноль:

$$S(x) \approx \frac{a^2}{4}\cdot x \cdot 2 = \frac{a^2 x}{2} \to 0.$$

Геометрически основание стягивается, треугольник превращается в отрезок длины $a$.

**$x \to 2$.** Тогда $\sqrt{4-x^2} \to 0$, и снова площадь обращается в ноль:

$$S(x) \approx \frac{a^2}{4}\cdot 2 \cdot \sqrt{4-x^2} \to 0.$$

Геометрически основание $c \to 2a$, треугольник «расплющивается»: вершина $A$ опускается на основание, и площадь исчезает.

В обоих случаях треугольник вырождается, и площадь стремится к нулю. Между этими крайностями где-то должен быть максимум.

### Максимум площади

Чтобы найти максимум $S(x)$, удобнее работать с $f(x)^2 = x^2(4-x^2) = 4x^2 - x^4$ (функция $f$ положительна, поэтому максимум $f$ — там же, где максимум $f^2$).

Производная по $x$:

$$\frac{d}{dx}\bigl(4x^2 - x^4\bigr) = 8x - 4x^3 = 4x(2 - x^2).$$

На интервале $0 < x < 2$ корни производной: $x = 0$ (граница, отбрасываем) и $x = \sqrt{2}$.

В точке $x = \sqrt{2}$:

$$S(\sqrt{2}) = \frac{a^2}{4}\cdot \sqrt{2}\cdot\sqrt{4-2} = \frac{a^2}{4}\cdot\sqrt{2}\cdot\sqrt{2} = \frac{a^2}{2}.$$

!!! important "Главный геометрический факт"
    Среди равнобедренных треугольников с фиксированными боковыми сторонами $a$ **наибольшую площадь имеет равнобедренный прямоугольный** (с катетами $a$ и гипотенузой $a\sqrt{2}$). Его площадь — ровно $a^2/2$, как у половины квадрата со стороной $a$.

Это согласуется с известным фактом: при фиксированных двух сторонах площадь $S = \tfrac{1}{2}ab\sin C$ максимальна, когда угол между ними прямой ($\sin C = 1$).

### Равносторонний случай

Подставим $x = 1$ (равносторонний):

$$S(1) = \frac{a^2}{4}\cdot 1\cdot\sqrt{3} = \frac{a^2 \sqrt{3}}{4}.$$

Это знаменитая формула площади равностороннего треугольника. У неё «средняя» позиция: $S(1) \approx 0.433\,a^2$, тогда как максимум $S(\sqrt 2) = 0.5\,a^2$. То есть равносторонний треугольник **не самый большой** среди равнобедренных с боковой $a$ — он проигрывает прямоугольному.

## 8.9.6. Неожиданная симметрия: $x_1^2 + x_2^2 = 4$

Вернёмся к загадке из §8.9.1. У нас $a = 10$, и площади $S(x_1) = S(x_2) = 48$ при $x_1 = 16/10 = 1.6$ и $x_2 = 12/10 = 1.2$. Сложим квадраты:

$$1.6^2 + 1.2^2 = 2.56 + 1.44 = 4.$$

Случайность? Проверим ещё пары. Возьмём, например, равносторонний $x_1 = 1$. Чтобы найти второй $x$ с такой же площадью, решим:

$$x_2\sqrt{4-x_2^2} = 1\cdot\sqrt{3}.$$

Возведя в квадрат: $x_2^2(4 - x_2^2) = 3$. Обозначим $t = x_2^2$:

$$t(4 - t) = 3 \;\Longleftrightarrow\; t^2 - 4t + 3 = 0 \;\Longleftrightarrow\; t = 1 \text{ или } t = 3.$$

Корень $t = 1$ — это сам равносторонний $x_2 = 1$. Новый ответ: $t = 3$, то есть $x_2 = \sqrt{3}$. Сложим квадраты:

$$1^2 + (\sqrt 3)^2 = 1 + 3 = 4. \quad\checkmark$$

Гипотеза подтверждается. Сформулируем её и докажем.

!!! abstract "Симметрия равных площадей"
    Два равнобедренных треугольника с одной и той же боковой стороной $a$ и параметрами формы $x_1 = c_1/a$ и $x_2 = c_2/a$ имеют **одинаковую площадь** тогда и только тогда, когда

    $$x_1^2 + x_2^2 = 4,$$

    то есть $c_1^2 + c_2^2 = 4a^2$.

**Доказательство.** Покажем, что $S(x_1) = S(x_2)$ равносильно $x_1^2 + x_2^2 = 4$.

Возведём $S(x_1) = S(x_2)$ в квадрат и поделим на общий множитель:

$$x_1^2(4 - x_1^2) = x_2^2(4 - x_2^2).$$

Перепишем как разность:

$$x_1^2(4 - x_1^2) - x_2^2(4 - x_2^2) = 0,$$

$$4(x_1^2 - x_2^2) - (x_1^4 - x_2^4) = 0,$$

$$(x_1^2 - x_2^2)\bigl[4 - (x_1^2 + x_2^2)\bigr] = 0.$$

Произведение равно нулю — либо $x_1^2 = x_2^2$ (т. е. $x_1 = x_2$, тот же треугольник), либо

$$x_1^2 + x_2^2 = 4. \qquad\blacksquare$$

**Проверим на наших примерах:**

- $1.6^2 + 1.2^2 = 4$ ✓ → треугольники $10,10,16$ и $10,10,12$.
- $1^2 + (\sqrt 3)^2 = 4$ ✓ → равносторонний $a,a,a$ и треугольник со сторонами $a, a, a\sqrt 3$.
- $\sqrt 2^2 + \sqrt 2^2 = 4$ ✓ → «неподвижная точка»: единственный треугольник, симметричный сам себе, — это равнобедренный прямоугольный (где и достигается максимум площади).

!!! tip "Удобная переформулировка"
    Зафиксировав $a$, отображение $\varphi\colon x \mapsto \sqrt{4 - x^2}$ — инволюция на $(0, 2)$ (то есть $\varphi(\varphi(x)) = x$). Она «склеивает» точки $x$ и $\sqrt{4-x^2}$, оставляя на месте только $x = \sqrt 2$. Площадь $S$ — функция, **постоянная** на каждой такой паре. (Подробнее об инволюциях см. [§2.6 «Идемпотентные функции»](../algebra/idempotent.md).)

## 8.9.7. Геометрический смысл симметрии

Алгебра — это здорово, но за каждым тождеством стоит геометрическая картина. Какая она здесь?

Вернёмся к разрезанию равнобедренного треугольника высотой пополам. Любой такой треугольник $a, a, c$ — это **два сложенных по катету одинаковых прямоугольных треугольника** с катетами $c/2$ и $h = \sqrt{a^2 - c^2/4}$ и гипотенузой $a$.

```
       A                     A
      /|                     |\
     / |                     | \
    /  |          и          |  \
   /   |                     |   \
  B----H                     H----C
```

Площадь равнобедренного — это удвоенная площадь одного из этих прямоугольных:

$$S = 2\cdot\frac{1}{2}\cdot\frac{c}{2}\cdot h = \frac{c}{2}\cdot h.$$

Теперь главный вопрос: **что мы знаем про эти прямоугольные треугольники?**

У них фиксирована **гипотенуза $a$** и сумма квадратов катетов:

$$\left(\frac{c}{2}\right)^2 + h^2 = a^2.$$

Обозначим катеты $p = c/2$ и $q = h$. Тогда $p^2 + q^2 = a^2$, а площадь прямоугольного — $\tfrac{1}{2}pq$.

!!! important "Ключевое наблюдение"
    Из одной и той же пары катетов $\{p, q\}$ можно собрать **два** разных равнобедренных треугольника — назначив роли «половины основания» и «высоты» по-разному:

    - вариант A: $p$ — половина основания, $q$ — высота → треугольник со сторонами $a, a, 2p$;
    - вариант B: $q$ — половина основания, $p$ — высота → треугольник со сторонами $a, a, 2q$.

    Площадь обоих — $\tfrac{c}{2}\cdot h = pq$, то есть **одинакова**. Это и есть та самая симметрия.

**Применим к загадке.** Прямоугольный треугольник с гипотенузой $10$ и катетами $6$ и $8$ существует:

$$6^2 + 8^2 = 36 + 64 = 100 = 10^2. \quad\checkmark$$

Из него собираем два равнобедренных:

- $p = 6$ как половина основания, $q = 8$ как высота → треугольник $10, 10, 12$.
- $p = 8$ как половина основания, $q = 6$ как высота → треугольник $10, 10, 16$.

Площадь обоих — $pq = 6\cdot 8 = 48$. Загадка раскрыта.

**А алгебраическая симметрия?** Параметры $x_1 = 2p/a$ и $x_2 = 2q/a$. Тогда

$$x_1^2 + x_2^2 = \frac{4p^2 + 4q^2}{a^2} = \frac{4(p^2 + q^2)}{a^2} = \frac{4a^2}{a^2} = 4.$$

То есть тождество $x_1^2 + x_2^2 = 4$ — это просто теорема Пифагора, переписанная в параметрах формы.

## 8.9.8. Скрытая связь с пифагоровыми тройками

Мы выяснили: каждый прямоугольный треугольник с гипотенузой $a$ порождает **пару** равнобедренных треугольников с боковой стороной $a$ и одинаковой площадью.

А когда такая пара получается **целочисленной** — то есть с целыми сторонами и целой площадью? Ровно тогда, когда катеты $p, q$ и гипотенуза $a$ — целые числа, удовлетворяющие $p^2 + q^2 = a^2$. Это и есть определение **пифагоровой тройки**.

!!! abstract "Главный мост"
    Каждой пифагоровой тройке $(p, q, a)$ соответствует пара целочисленных равнобедренных треугольников с одинаковой площадью:

    $$\boxed{\; (a, a, 2p) \quad\text{и}\quad (a, a, 2q), \qquad S = pq. \;}$$

**Каталог пар.** Перебрав небольшие пифагоровы тройки (полный обзор — в §10.2.3), получаем:

| Пифагорова тройка $(p, q, a)$ | Пара равнобедренных | Общая площадь |
|---|---|---|
| $(3, 4, 5)$ | $(5, 5, 6)$ и $(5, 5, 8)$ | $12$ |
| $(6, 8, 10)$ | $(10, 10, 12)$ и $(10, 10, 16)$ | $48$ |
| $(5, 12, 13)$ | $(13, 13, 10)$ и $(13, 13, 24)$ | $60$ |
| $(8, 15, 17)$ | $(17, 17, 16)$ и $(17, 17, 30)$ | $120$ |
| $(9, 12, 15)$ | $(15, 15, 18)$ и $(15, 15, 24)$ | $108$ |
| $(7, 24, 25)$ | $(25, 25, 14)$ и $(25, 25, 48)$ | $168$ |

Наш «10,10,16 vs 10,10,12»-парадокс — это просто строка №2: тройка $(6, 8, 10)$, удвоенная классическая $(3, 4, 5)$.

**Проверка через программу.** Сгенерируем все пары для тройки $(p, q, a)$ и подтвердим равенство площадей:

```python
import math

def heron(a, b, c):
    s = (a + b + c) / 2
    return math.sqrt(s * (s - a) * (s - b) * (s - c))

# Пифагоровы тройки p^2 + q^2 = a^2 с p < q < a, a <= 25
triples = [(p, q, a) for a in range(1, 26)
                    for q in range(1, a)
                    for p in range(1, q)
                    if p*p + q*q == a*a]

for p, q, a in triples:
    s1 = heron(a, a, 2*p)
    s2 = heron(a, a, 2*q)
    print(f"({p:2d},{q:2d},{a:2d}) -> "
          f"({a},{a},{2*p}) и ({a},{a},{2*q}), S = {s1:.1f} = {s2:.1f}")
```

Программа подтвердит: каждая пифагорова тройка с гипотенузой $\le 25$ даёт пару равнобедренных треугольников с одинаковой целой площадью.

### А что с рациональными решениями?

В целочисленном варианте мы нашли пары через пифагоровы тройки. А что если допустить **рациональные** длины сторон? Окажется — пар становится несчётно много, и они описываются ровно теми же тройками — только умноженными на произвольный рациональный множитель.

Пусть $x = c/a$ — рациональное число $p/q$ в несократимой форме. Когда $S(x) = \tfrac{a^2}{4}\,x\sqrt{4 - x^2}$ рационально (при рациональном $a$)? Нужно, чтобы $\sqrt{4 - x^2}$ было рационально, то есть

$$4 - \frac{p^2}{q^2} = \frac{(2q)^2 - p^2}{q^2}$$

было квадратом рационального. Это значит, что число $(2q)^2 - p^2 = m^2$ для некоторого целого $m$, или

$$p^2 + m^2 = (2q)^2.$$

Тройка $(p, m, 2q)$ — снова пифагорова! Так что **рациональные равнобедренные треугольники с рациональной площадью** — это в точности пропорциональные «пифагоровым» равнобедренным.

!!! note "Параметрический мост"
    В §10.2.3 параметризация пифагоровых троек дана формулами $p = m^2 - n^2$, $q = 2mn$, $a = m^2 + n^2$. Подставив их в нашу пару $(a, a, 2p)$ и $(a, a, 2q)$ и считая площадь, получаем

    $$S = pq = 2mn(m^2 - n^2) = 2mn(m-n)(m+n).$$

    Это ещё одно лицо той же формулы: каждая пара параметров $(m, n)$ задаёт тройку, тройка задаёт пару равнобедренных, пара задаёт площадь.

### Маленькая олимпиадная задача

Рассмотрим один классический сюжет, на котором эти идеи срабатывают: **найти все целочисленные равнобедренные треугольники с целой площадью**, у которых боковая сторона равна $25$.

По нашему рецепту нужны все способы представить $25^2 = 625$ как сумму двух квадратов натуральных чисел. Прямой перебор даёт ровно две неупорядоченные пары:

- $\{7, 24\}$, поскольку $7^2 + 24^2 = 49 + 576 = 625$;
- $\{15, 20\}$, поскольку $15^2 + 20^2 = 225 + 400 = 625$ (это тройка $5\cdot(3, 4, 5)$).

Каждая пара $\{p, q\}$ даёт два равнобедренных треугольника с основаниями $2p$ и $2q$:

| Тройка | Пара треугольников | Общая площадь $pq$ |
|---|---|---|
| $(7, 24, 25)$ | $(25, 25, 14)$ и $(25, 25, 48)$ | $168$ |
| $(15, 20, 25)$ | $(25, 25, 30)$ и $(25, 25, 40)$ | $300$ |

Итого четыре равнобедренных треугольника, разбитых на две пары по равенству площадей — ровно из-за симметрии $x_1^2 + x_2^2 = 4$. Никаких других целочисленных решений нет: количество представлений $625$ суммой двух квадратов конечно, и мы их перечислили.

---

!!! abstract "Резюме главы"
    - **Загадка** ($10, 10, 16$ и $10, 10, 12$ имеют одну площадь $48$) объясняется **симметрией формы**, а не совпадением.
    - Площадь равнобедренного треугольника $a, a, c$: $\;S = \tfrac{c}{2}\sqrt{a^2 - c^2/4}$.
    - **Нормализация** $x = c/a$ даёт $\;S(x) = \tfrac{a^2}{4}\,x\sqrt{4 - x^2}$, $\;0 < x < 2$.
    - **Максимум площади** — при $x = \sqrt 2$ (равнобедренный прямоугольный, $S_\max = a^2/2$).
    - **Симметрия:** $S(x_1) = S(x_2) \iff x_1^2 + x_2^2 = 4$, то есть $c_1^2 + c_2^2 = 4a^2$.
    - **Геометрия симметрии:** один прямоугольный треугольник с гипотенузой $a$ и катетами $p, q$ собирается в **два** равнобедренных — $(a, a, 2p)$ и $(a, a, 2q)$ — с площадью $pq$.
    - **Скрытая связь с пифагоровыми тройками:** каждая тройка $(p, q, a)$ генерирует пару целочисленных равнобедренных треугольников с одинаковой целой площадью; «10,10,16 / 10,10,12» — это тройка $(6, 8, 10)$.
