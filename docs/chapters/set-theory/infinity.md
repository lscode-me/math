# Глава 15.1. Основания математики и природа бесконечности

## 15.1.1. Счётная бесконечность: отель Гильберта

Давид Гильберт придумал мысленный эксперимент, демонстрирующий парадоксальную природу бесконечности.

**Отель Гильберта** — гостиница с бесконечным числом номеров ($1, 2, 3, \ldots$), и все номера заняты.

- **Приезжает 1 гость.** Просим постояльца из №1 перейти в №2, из №2 — в №3, и так далее. Номер №1 освобождается.

- **Приезжает бесконечно много гостей** (автобус с пронумерованными местами). Просим постояльца из №$k$ перейти в №$2k$. Нечётные номера ($1, 3, 5, \ldots$) освобождаются — можно разместить всех новых гостей.

- **Приезжает бесконечно много автобусов**, в каждом бесконечно много гостей. Нумеруем гостя автобуса $m$, места $n$ числом $2^m 3^n$ — и это лишь один из способов найти взаимно однозначное соответствие.

**Вывод:** Бесконечные множества бывают «одного размера», даже если одно «явно больше». Размер бесконечного множества измеряется его **мощностью**.

---

## 15.1.2. Мощности множеств

Два множества **равномощны** (имеют одну мощность), если между ними существует **взаимно однозначное соответствие** (биекция).

**Натуральные числа $\mathbb{N}$ и чётные числа равномощны:** $n \leftrightarrow 2n$.

**Натуральные числа и целые числа равномощны:** $0, 1, -1, 2, -2, 3, -3, \ldots$ — список без пропусков.

**Натуральные числа и рациональные числа $\mathbb{Q}$ равномощны.** Доказательство: выписать все дроби $p/q$ в таблицу и обойти её диагоналями (диагонализация Кантора):

$$\frac{1}{1}, \frac{2}{1}, \frac{1}{2}, \frac{1}{3}, \frac{2}{2}, \frac{3}{1}, \frac{4}{1}, \frac{3}{2}, \ldots$$

Все рациональные числа попадают в этот список — значит, $|\mathbb{Q}| = |\mathbb{N}|$.

Счётное множество — бесконечное, равномощное $\mathbb{N}$. Обозначение: $|\mathbb{N}| = \aleph_0$ (алеф-ноль).

## 15.1.3. Диагональный аргумент Кантора: несчётность $\mathbb{R}$

!!! important "Теорема Кантора"
    Множество вещественных чисел $\mathbb{R}$ **несчётно**: нет биекции между $\mathbb{N}$ и $\mathbb{R}$.

**Доказательство** (диагональный аргумент).

Предположим, что все вещественные числа из $(0, 1)$ можно пронумеровать: $r_1, r_2, r_3, \ldots$ Запишем их в виде бесконечных десятичных дробей:

$$r_1 = 0.d_{11}d_{12}d_{13}d_{14}\ldots$$
$$r_2 = 0.d_{21}d_{22}d_{23}d_{24}\ldots$$
$$r_3 = 0.d_{31}d_{32}d_{33}d_{34}\ldots$$

Построим число $x = 0.x_1 x_2 x_3 \ldots$, где:

$$x_i = \begin{cases} 5 & \text{если } d_{ii} \neq 5 \\ 6 & \text{если } d_{ii} = 5 \end{cases}$$

Число $x$ отличается от $r_n$ в $n$-м знаке для любого $n$ — значит, $x$ не входит в список. Противоречие с предположением, что все вещественные числа пронумерованы. $\blacksquare$

Мощность $\mathbb{R}$ обозначается $\mathfrak{c} = 2^{\aleph_0}$ (континуум).

## 15.1.4. Иерархия бесконечностей

Кантор показал, что бесконечностей **бесконечно много** — каждая «строго больше» предыдущей:

$$\aleph_0 < 2^{\aleph_0} < 2^{2^{\aleph_0}} < \ldots$$

**Теорема Кантора** в общем виде: $|A| < |2^A|$ для любого множества $A$ (мощность множества всех подмножеств строго больше мощности самого множества).

**Континуум-гипотеза** (Кантор, 1878): нет множества с мощностью строго между $\aleph_0$ и $\mathfrak{c}$. То есть $\mathfrak{c} = \aleph_1$ — следующий кардинал после счётного.

**Шок 1963 года.** Пол Коэн доказал (используя метод «форсинг»), что континуум-гипотеза **независима** от аксиом Цермело–Френкеля (ZFC). Это значит: в стандартной математике нельзя ни доказать, ни опровергнуть континуум-гипотезу. Можно строить математику, где она верна, и математику, где она неверна — обе непротиворечивы.

## 15.1.5. Парадокс Рассела и кризис теории множеств

Ранняя «наивная» теория множеств разрешала любое «определение» образовывать множество: множество всех красных вещей, множество всех простых чисел, etc.

В 1902 году Бертран Рассел нашёл смертельное противоречие:

!!! important "Парадокс Рассела"
    Рассмотрим множество $R = \{X : X \notin X\}$ — множество всех множеств, не содержащих самих себя.
    
    - Если $R \in R$: тогда по определению $R \notin R$. Противоречие.
    - Если $R \notin R$: тогда $R$ удовлетворяет условию, то есть $R \in R$. Противоречие.

«Брадобрей, который бреет всех, кто не бреется сам» — это бытовая аналогия: такой брадобрей не может существовать. Точно так же множество $R$ не может существовать в наивной теории.

**Выход:** Аксиоматическая теория множеств (ZFC) запрещает «самореференцию» через тщательно прописанные аксиомы. Каждое множество строится из других множеств — нельзя «с нуля» создать «множество всех множеств».

## 15.1.6. Теорема Гёделя о неполноте

Ещё один потрясающий результат XX века, переворачивающий представление о математике.

!!! important "Первая теорема Гёделя о неполноте (1931)"
    Любая достаточно богатая непротиворечивая формальная система (включающая арифметику) содержит утверждения, которые нельзя ни доказать, ни опровергнуть в рамках этой системы.

**Идея доказательства.** Гёдель построил формулу $G$, которая (в некотором смысле) утверждает: «Эта формула недоказуема». Если $G$ доказуема — система противоречива. Если $G$ недоказуема — значит $G$ истинна (и при этом недоказуема). В обоих случаях система неполна.

**Вторая теорема Гёделя:** достаточно богатая система не может доказать собственную непротиворечивость.

**Что это означает практически?** Математика никогда не будет «завершена»: всегда найдётся что-то истинное, чего нельзя доказать из данных аксиом. Это не ограничение наших способностей — это **фундаментальное свойство** формальных систем.

!!! abstract "Резюме главы"
    - Бесконечные множества «равны по размеру», если между ними есть биекция; $|\mathbb{N}| = |\mathbb{Q}|$
    - **Диагональный аргумент Кантора**: $\mathbb{R}$ несчётно
    - Бесконечностей бесконечно много: $\aleph_0 < 2^{\aleph_0} < \ldots$
    - **Парадокс Рассела** сломал наивную теорию множеств; ZFC — аксиоматический выход
    - **Теорема Гёделя**: в любой достаточно богатой системе есть недоказуемые истины
