# Глава 7.4. Метод бесконечного спуска

## 7.4.1. Идея Ферма

В XVII веке Пьер де Ферма разработал элегантный метод доказательства, который он называл «бесконечным спуском» (descente infinie). Идея такова:

!!! important "Метод бесконечного спуска"
    Предположим, что некоторое утверждение $P$ ложно, то есть существует **«плохой»** объект. Покажем, что из любого «плохого» объекта можно построить ещё **меньший** «плохой» объект. Поскольку убывающая последовательность натуральных чисел не может быть бесконечной (рано или поздно достигнет нуля или отрицательных — куда пути нет), это **противоречие** доказывает исходное утверждение $P$.

Формально: если из существования натурального числа $n$ с некоторым свойством следует существование **меньшего** натурального числа с тем же свойством — то таких чисел не существует вовсе.

## 7.4.2. Иррациональность $\sqrt{2}$: версия спуском

В главе 7.3 мы доказывали иррациональность $\sqrt{2}$ стандартным методом от противного. Ферма предложил другой взгляд на то же доказательство.

**Теорема.** $\sqrt{2}$ иррационально.

**Доказательство методом спуска.**

Предположим, $\sqrt{2} = \frac{p}{q}$ с $p, q \in \mathbb{N}$, $q$ — **наименьшее** возможное.

Тогда $p = q\sqrt{2}$, и $p^2 = 2q^2$. Введём $p' = 2q - p$ и $q' = p - q$.

Проверим: $p'^2 - 2q'^2 = (2q-p)^2 - 2(p-q)^2 = 4q^2 - 4pq + p^2 - 2p^2 + 4pq - 2q^2 = 2q^2 - p^2 = 0$.

Значит $\frac{p'}{q'} = \sqrt{2}$ — тоже представление.

Оценим $q'$: $q' = p - q = q\sqrt{2} - q = q(\sqrt{2} - 1) < q$ (так как $\sqrt{2} < 2$).

Также $q' > 0$: $q' = p - q > 0$ iff $p > q$ iff $\sqrt{2} > 1$ — верно.

Итого: получили представление $\sqrt{2} = \frac{p'}{q'}$ с **меньшим** знаменателем $q' < q$. Это противоречит минимальности $q$. $\blacksquare$

## 7.4.3. Уравнение $x^2 + y^2 = 3z^2$ не имеет целых решений (кроме нулевого)

**Теорема.** Уравнение $x^2 + y^2 = 3z^2$ не имеет решений в целых числах, кроме $x = y = z = 0$.

**Доказательство.**

Предположим, что $(x, y, z)$ — ненулевое решение. Выберем решение с **наименьшим** значением $|x| + |y| + |z| > 0$.

Рассмотрим остатки по модулю 3. Квадрат целого числа $\equiv 0$ или $1 \pmod{3}$ (так как $0^2 = 0$, $1^2 = 1$, $2^2 = 4 \equiv 1$).

Левая часть $x^2 + y^2 \equiv 0, 1, $ или $2 \pmod{3}$.

Правая часть $3z^2 \equiv 0 \pmod{3}$.

Значит $x^2 + y^2 \equiv 0 \pmod{3}$. Это возможно только при $x^2 \equiv y^2 \equiv 0 \pmod{3}$, то есть $3 \mid x$ и $3 \mid y$.

Пусть $x = 3x_1$, $y = 3y_1$. Подставим:

$$9x_1^2 + 9y_1^2 = 3z^2 \quad \Rightarrow \quad 3(x_1^2 + y_1^2) = z^2 \quad \Rightarrow \quad 3 \mid z$$

Пусть $z = 3z_1$. Тогда:

$$3(x_1^2 + y_1^2) = 9z_1^2 \quad \Rightarrow \quad x_1^2 + y_1^2 = 3z_1^2$$

Получили новое решение $(x_1, y_1, z_1) = (x/3, y/3, z/3)$ с $|x_1| + |y_1| + |z_1| = \frac{|x| + |y| + |z|}{3}$ — **меньшее**, чем исходное!

Это противоречит минимальности. Значит, ненулевых решений нет. $\blacksquare$

## 7.4.4. Связь с моновариантами

Метод бесконечного спуска — частный случай идеи **моноварианта** (которую мы встречали в главе 4.3).

В задачах на игры и процессы: если на каждом шаге некоторая характеристика (натуральное число) **строго убывает**, то процесс рано или поздно закончится.

В методе спуска: если из каждого «плохого» объекта мы строим **строго меньший** «плохой» объект, то по принципу наименьшего элемента «плохих» объектов нет.

**Формальная эквивалентность с индукцией.** Метод спуска равносилен сильной индукции: вместо «база + шаг» доказываем «нет наименьшего контрпримера».

| Метод | Структура |
|-------|-----------|
| Прямая индукция | Из $P(k)$ доказать $P(k+1)$ |
| Метод спуска | Из контрпримера $n$ построить меньший контрпример |
| Наименьший элемент | Нет наименьшего контрпримера → нет ни одного |

Все три подхода логически равносильны — это лишь разные способы выразить одну и ту же идею упорядоченности натурального ряда.

## 7.4.5. Теорема Ферма о суммах двух квадратов

Ферма использовал спуск, чтобы доказать, что простое $p \equiv 1 \pmod{4}$ представимо в виде $p = a^2 + b^2$. Полное доказательство требует модулярной арифметики (глава о теории чисел), но идея спуска такова:

1. Если $p \mid a^2 + b^2$ и $a^2 + b^2 < 2p$, найти меньшее $a'^2 + b'^2$ делящееся на $p$.
2. Продолжать спуск, пока не получим $a'^2 + b'^2 = p$.

Это сочетание спуска с явными алгебраическими преобразованиями — красота метода.

## 7.4.6. Применение в задачах

**Задача.** Докажите, что если натуральные числа $a, b$ удовлетворяют $a^2 = 2b^2$, то $a = b = 0$.

Это то же, что иррациональность $\sqrt{2}$: если $\frac{a}{b} = \sqrt{2}$, то $a^2 = 2b^2$, и мы уже знаем, что это невозможно при $a, b > 0$.

**Задача.** Докажите, что $\sqrt{3}$ иррационально.

Предположим $\sqrt{3} = \frac{p}{q}$ (несократимая дробь). Тогда $p^2 = 3q^2$.

$p^2 \equiv 0 \pmod{3}$ → $p \equiv 0 \pmod{3}$ → $p = 3k$ → $9k^2 = 3q^2$ → $q^2 = 3k^2$ → $q \equiv 0 \pmod{3}$. Противоречие с несократимостью. $\blacksquare$

Или методом спуска: предположить минимальный $q$ и построить меньший — аналогично разделу 7.4.2.

## Итоги главы

- Метод бесконечного спуска: из предположения о существовании «плохого» объекта строим меньший такой же — противоречие с принципом наименьшего элемента.
- Классика: иррациональность $\sqrt{2}$, отсутствие ненулевых решений $x^2 + y^2 = 3z^2$.
- Логически эквивалентен сильной индукции и принципу наименьшего элемента.
- Связан с идеей моноварианта: строго убывающий натуральный параметр не может убывать вечно.
- Придуман Ферма и использован им для доказательства ряда теорем теории чисел.
