# Глава 1.9. Комплексные числа

## 1.9.1. Мнимая единица

В [§1.4](operations.md) мы видели, что уравнение $x^2 = -1$ не имеет решений в вещественных числах, но математики были **вынуждены** работать с $\sqrt{-1}$, чтобы применять формулу Кардано для кубических уравнений.

Определим новый объект:

$$i^2 = -1$$

Число $i$ называется **мнимой единицей** (от латинского imaginarius — «воображаемый»). Это не вещественное число — это **новый элемент**, добавленный к числовой системе.

!!! note "Название «мнимый» — историческое недоразумение"
    Декарт назвал такие числа «мнимыми» в XVII веке, подразумевая, что они ненастоящие. Но комплексные числа не менее «реальны», чем отрицательные или иррациональные — они просто описывают другую математическую структуру. Гаусс предлагал вместо «мнимых» называть их **латеральными** (боковыми), но название не прижилось.

## 1.9.2. Алгебраическая форма

**Комплексное число** — это выражение вида:

$$z = a + bi$$

где $a, b \in \mathbb{R}$, а $i^2 = -1$.

- $a = \text{Re}(z)$ — **вещественная часть**
- $b = \text{Im}(z)$ — **мнимая часть**

| Пример | $\text{Re}$ | $\text{Im}$ | Тип |
|:------:|:-----------:|:-----------:|:---:|
| $3 + 2i$ | $3$ | $2$ | Комплексное |
| $-1 + 4i$ | $-1$ | $4$ | Комплексное |
| $5$ | $5$ | $0$ | Вещественное (частный случай) |
| $3i$ | $0$ | $3$ | Чисто мнимое |
| $0$ | $0$ | $0$ | Ноль |

Каждое вещественное число — комплексное с нулевой мнимой частью: $a = a + 0i$.

### Арифметика комплексных чисел

С комплексными числами можно складывать, вычитать, умножать и делить, используя обычные правила алгебры и подстановку $i^2 = -1$.

**Сложение и вычитание** — покомпонентно:

$$(a + bi) + (c + di) = (a+c) + (b+d)i$$

**Пример:** $(3 + 2i) + (1 - 5i) = 4 - 3i$.

**Умножение** — раскрытие скобок:

$$(a + bi)(c + di) = ac + adi + bci + bdi^2 = (ac - bd) + (ad + bc)i$$

**Пример:** $(2 + 3i)(1 - i) = 2 - 2i + 3i - 3i^2 = 2 + i + 3 = 5 + i$.

**Деление** — умножение числителя и знаменателя на **сопряжённое**:

$$\frac{a + bi}{c + di} = \frac{(a + bi)(c - di)}{(c + di)(c - di)} = \frac{(ac + bd) + (bc - ad)i}{c^2 + d^2}$$

**Сопряжённое** число к $z = a + bi$ — это $\bar{z} = a - bi$. Произведение числа на сопряжённое всегда вещественно:

$$z \cdot \bar{z} = (a + bi)(a - bi) = a^2 + b^2$$

**Пример:** $\frac{3 + i}{1 + 2i} = \frac{(3+i)(1-2i)}{(1+2i)(1-2i)} = \frac{3 - 6i + i - 2i^2}{1 + 4} = \frac{5 - 5i}{5} = 1 - i$.

## 1.9.3. Геометрический смысл: комплексная плоскость

Вещественные числа живут на **прямой**. Комплексные числа живут на **плоскости**.

Каждому комплексному числу $z = a + bi$ сопоставляется точка $(a, b)$ на координатной плоскости, где горизонтальная ось — вещественная, а вертикальная — мнимая. Эту плоскость называют **комплексной плоскостью** (или плоскостью Гаусса, или диаграммой Аргана).

| Ось | Что представляет | Примеры |
|-----|-----------------|---------|
| Горизонтальная | Вещественная часть | $\ldots, -2, -1, 0, 1, 2, \ldots$ |
| Вертикальная | Мнимая часть | $\ldots, -2i, -i, 0, i, 2i, \ldots$ |

Число $3 + 2i$ — это точка $(3, 2)$. Число $-1 + 4i$ — точка $(-1, 4)$. Чисто вещественные числа лежат на горизонтальной оси, чисто мнимые — на вертикальной.

### Модуль и аргумент

**Модуль** комплексного числа — расстояние от начала координат до точки $z$:

$$|z| = \sqrt{a^2 + b^2}$$

**Аргумент** — угол $\varphi$ между положительной вещественной осью и направлением на точку $z$:

$$\varphi = \arg(z), \quad \tan \varphi = \frac{b}{a}$$

**Пример:** $|3 + 4i| = \sqrt{9 + 16} = 5$, $\;\arg(3 + 4i) = \arctan\frac{4}{3} \approx 53.1°$.

### Геометрический смысл операций

- **Сложение** — сложение векторов (правило параллелограмма).
- **Умножение на $i$** — поворот на $90°$ против часовой стрелки:

$$i \cdot (a + bi) = -b + ai$$

Точка $(a, b)$ переходит в $(-b, a)$ — именно поворот на $90°$.

- **Умножение на $-1$** — поворот на $180°$ (отражение через начало координат).
- **Умножение двух комплексных чисел** — модули **перемножаются**, аргументы **складываются**.

!!! important "Умножение = масштабирование + поворот"
    При умножении $z_1 \cdot z_2$:

    - $|z_1 \cdot z_2| = |z_1| \cdot |z_2|$ (модули перемножаются)
    - $\arg(z_1 \cdot z_2) = \arg(z_1) + \arg(z_2)$ (аргументы складываются)

    Умножение на комплексное число — это одновременно **растяжение** (на $|z_2|$) и **поворот** (на $\arg(z_2)$).

## 1.9.4. Тригонометрическая форма

Используя модуль $r = |z|$ и аргумент $\varphi = \arg(z)$, любое ненулевое комплексное число можно записать:

$$z = r(\cos\varphi + i\sin\varphi)$$

Это **тригонометрическая форма** комплексного числа. Связь с алгебраической формой: $a = r\cos\varphi$, $b = r\sin\varphi$.

### Умножение в тригонометрической форме

Пусть $z_1 = r_1(\cos\varphi_1 + i\sin\varphi_1)$ и $z_2 = r_2(\cos\varphi_2 + i\sin\varphi_2)$. Тогда:

$$z_1 \cdot z_2 = r_1 r_2 \big(\cos(\varphi_1 + \varphi_2) + i\sin(\varphi_1 + \varphi_2)\big)$$

Модули перемножаются, аргументы складываются — в тригонометрической форме это видно напрямую.

### Формула Муавра

Следствие для возведения в степень:

$$z^n = r^n (\cos n\varphi + i\sin n\varphi)$$

Это **формула Муавра** — мощный инструмент для вычисления степеней комплексных чисел и вывода тригонометрических тождеств.

**Пример.** Вычислим $(1 + i)^8$.

Переведём в тригонометрическую форму: $|1+i| = \sqrt{2}$, $\arg(1+i) = 45° = \frac{\pi}{4}$.

$$(1 + i)^8 = (\sqrt{2})^8 \left(\cos 8 \cdot \frac{\pi}{4} + i\sin 8 \cdot \frac{\pi}{4}\right) = 16(\cos 2\pi + i\sin 2\pi) = 16$$

## 1.9.5. Формула Эйлера

Одна из самых красивых формул в математике:

$$e^{i\varphi} = \cos\varphi + i\sin\varphi$$

Эта формула связывает показательную функцию с тригонометрическими. При $\varphi = \pi$:

$$e^{i\pi} = \cos\pi + i\sin\pi = -1$$

или в более известной записи:

$$e^{i\pi} + 1 = 0$$

Пять фундаментальных констант математики — $e$, $i$, $\pi$, $1$ и $0$ — связаны одной формулой.

### Экспоненциальная форма комплексного числа

С формулой Эйлера тригонометрическая форма записывается компактно:

$$z = re^{i\varphi}$$

Умножение:

$$z_1 \cdot z_2 = r_1 e^{i\varphi_1} \cdot r_2 e^{i\varphi_2} = r_1 r_2 \, e^{i(\varphi_1 + \varphi_2)}$$

Модули перемножаются, аргументы складываются — правило, которое мы уже знаем, но теперь оно следует из обычных свойств показательной функции.

---

## 1.9.6. Основная теорема алгебры

Зачем нужны комплексные числа? Помимо решения $x^2 = -1$, у них есть замечательное свойство:

!!! important "Основная теорема алгебры"
    Любой многочлен степени $n \geq 1$ с комплексными (в частности, вещественными) коэффициентами имеет **ровно $n$ корней** в $\mathbb{C}$ (с учётом кратности).

Это значит, что комплексные числа — **алгебраически замкнутое** поле: любое полиномиальное уравнение разрешимо. Никаких дальнейших расширений для решения алгебраических уравнений не нужно.

Примеры:

- $x^2 + 1 = 0$ имеет 2 корня: $x = i$ и $x = -i$.
- $x^2 - 2x + 5 = 0$: дискриминант $D = 4 - 20 = -16 < 0$. Корни: $x = \frac{2 \pm \sqrt{-16}}{2} = \frac{2 \pm 4i}{2} = 1 \pm 2i$.
- $x^3 - 1 = 0$ имеет 3 корня: $x = 1$, $x = -\frac{1}{2} + \frac{\sqrt{3}}{2}i$, $x = -\frac{1}{2} - \frac{\sqrt{3}}{2}i$ (три кубических корня из единицы).

!!! tip "Корни из единицы"
    Уравнение $x^n = 1$ имеет ровно $n$ комплексных корней, равномерно расположенных на единичной окружности ($|z| = 1$):

    $$x_k = \cos\frac{2\pi k}{n} + i\sin\frac{2\pi k}{n} = e^{2\pi i k/n}, \quad k = 0, 1, \ldots, n-1$$

    Для $n = 4$: корни — это $1, i, -1, -i$ (вершины квадрата на единичной окружности).

---

!!! abstract "Резюме главы"
    - Мнимая единица $i$ определяется свойством $i^2 = -1$
    - Комплексное число $z = a + bi$ имеет вещественную часть $a$ и мнимую часть $b$
    - Арифметика комплексных чисел: сложение покомпонентно, умножение через $i^2 = -1$, деление через сопряжённое
    - На **комплексной плоскости** число $a + bi$ — это точка $(a, b)$; умножение — масштабирование и поворот
    - **Тригонометрическая форма**: $z = r(\cos\varphi + i\sin\varphi)$; при умножении модули перемножаются, аргументы складываются
    - **Формула Эйлера**: $e^{i\varphi} = \cos\varphi + i\sin\varphi$; частный случай $e^{i\pi} + 1 = 0$ связывает пять фундаментальных констант
    - **Основная теорема алгебры**: любой многочлен степени $n$ имеет ровно $n$ комплексных корней

---

!!! tip "Что дальше"
    Мы расширили числовую систему до $\mathbb{C}$ и получили алгебраическую замкнутость. Но числа таят ещё один сюрприз: в [§1.10 «Гипотеза Коллатца»](collatz.md) мы увидим, как простейшая операция над натуральными числами — «если чётное, раздели пополам; если нечётное, утрой и прибавь один» — порождает задачу, которую математики не могут решить уже почти сто лет.
