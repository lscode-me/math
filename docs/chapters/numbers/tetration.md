# Глава 1.7. Тетрация

## 1.7.1. Лестница операций

Сложение, умножение и возведение в степень — три арифметические операции, знакомые каждому. Но между ними есть глубокая связь: каждая следующая — это **повторение** предыдущей.

**Умножение** — это повторное сложение:

$$a \times n = \underbrace{a + a + \ldots + a}_{n \text{ раз}}$$

**Возведение в степень** — это повторное умножение:

$$a^n = \underbrace{a \times a \times \ldots \times a}_{n \text{ раз}}$$

Естественный вопрос: а что будет, если **повторить возведение в степень**?

---

## 1.7.2. Тетрация: повторное возведение в степень

**Тетрация** — это повторное возведение в степень:

$${}^{n}a = \underbrace{a^{a^{a^{\cdot^{\cdot^{\cdot^a}}}}}}_{n \text{ раз}}$$

Обозначение ${}^{n}a$ читается как «$a$ в башне высоты $n$». Вычисление производится **справа налево** (сверху вниз в башне):

$${}^{3}2 = 2^{2^2} = 2^4 = 16$$

$${}^{4}2 = 2^{2^{2^2}} = 2^{2^4} = 2^{16} = 65\,536$$

$${}^{5}2 = 2^{2^{2^{2^2}}} = 2^{65536} \approx 2 \times 10^{19728}$$

!!! warning "Порядок вычислений важен"
    Возведение в степень **не ассоциативно**: $(2^2)^2 = 4^2 = 16$, но $2^{(2^2)} = 2^4 = 16$ — совпало случайно. Уже для $(2^3)^2 = 8^2 = 64$, а $2^{(3^2)} = 2^9 = 512$. В тетрации скобки **всегда** ставятся справа: $a^{(a^{(a^{\cdots})})}$.

Посмотрим, как быстро растёт тетрация:

| $n$ | ${}^{n}2$ | ${}^{n}3$ |
|:---:|:---------:|:---------:|
| 1 | $2$ | $3$ |
| 2 | $2^2 = 4$ | $3^3 = 27$ |
| 3 | $2^{2^2} = 16$ | $3^{3^3} = 3^{27} = 7\,625\,597\,484\,987$ |
| 4 | $2^{2^{2^2}} = 65\,536$ | $3^{3^{3^3}} = 3^{7625597484987}$ — число с $\approx 3.6$ триллионами цифр |
| 5 | число с $\approx 20\,000$ цифрами | невообразимо |

Уже ${}^{4}3$ — число, для записи которого не хватит всех атомов наблюдаемой Вселенной (в ней примерно $10^{80}$ атомов). Тетрация растёт **невообразимо** быстрее возведения в степень.

## 1.7.3. Сводная таблица операций

| Операция | Обозначение | Определение | Пример |
|----------|:-----------:|:-----------:|:------:|
| Сложение | $a + n$ | $a + n$ | $3 + 4 = 7$ |
| Умножение | $a \times n$ | $\underbrace{a + a + \ldots + a}_{n}$ | $3 \times 4 = 12$ |
| Степень | $a^n$ | $\underbrace{a \times a \times \ldots \times a}_{n}$ | $3^4 = 81$ |
| Тетрация | ${}^{n}a$ | $\underbrace{a^{a^{a^{\cdot^{\cdot^{\cdot}}}}}}_{n}$ | ${}^{4}3 \approx 10^{3.6 \times 10^{12}}$ |

Каждая следующая операция «на порядок» мощнее предыдущей. Переход от сложения к умножению кажется естественным; от умножения к степени — уже значительным скачком; от степени к тетрации — взрывным.

## 1.7.4. Стрелочная нотация Кнута

Для записи гиперопераций Дональд Кнут (создатель системы $\TeX$ и автор «Искусства программирования») предложил **стрелочную нотацию** (1976):

| Нотация | Операция | Значение |
|:-------:|----------|----------|
| $a \uparrow b$ | Возведение в степень | $a^b$ |
| $a \uparrow\uparrow b$ | Тетрация | ${}^{b}a$ |
| $a \uparrow\uparrow\uparrow b$ | Пентация | Повторная тетрация |
| $a \uparrow^n b$ | $n$-я гипероперация | $n$ стрелок |

Каждая дополнительная стрелка означает «повторение предыдущей операции». Пентация ($\uparrow\uparrow\uparrow$) — это повторная тетрация:

$$3 \uparrow\uparrow\uparrow 3 = 3 \uparrow\uparrow (3 \uparrow\uparrow 3) = 3 \uparrow\uparrow 7625597484987 = {}^{7625597484987}3$$

Это башня из троек высотой $7.6$ триллиона — число, которое не просто невозможно записать, а невозможно даже описать количество цифр в нём.

## 1.7.5. Число Грэма

Стрелочная нотация позволяет записывать невообразимо большие числа, но даже она недостаточна для некоторых величин.

**Число Грэма** ($G$) — одно из самых больших чисел, когда-либо использованных в математическом доказательстве. Оно возникло в задаче комбинаторной геометрии (теории Рамсея) в 1971 году.

Определяется рекуррентно. Начнём с:

$$g_1 = 3 \uparrow\uparrow\uparrow\uparrow 3 = 3 \uparrow^4 3$$

Уже $g_1$ — число, запредельно превосходящее всё, что мы обсуждали. Далее:

$$g_2 = 3 \uparrow^{g_1} 3 \quad \text{(количество стрелок равно } g_1\text{!)}$$

$$g_3 = 3 \uparrow^{g_2} 3$$

$$\vdots$$

$$G = g_{64}$$

Шестьдесят четыре таких шага. На каждом шаге количество стрелок равно **результату предыдущего шага** — числу, которое уже невозможно осмыслить.

!!! tip "Последняя цифра"
    Несмотря на невообразимую величину, **последние цифры** числа Грэма можно вычислить. Его последняя цифра — **7**. Последние $500$ цифр тоже известны. Это возможно благодаря модулярной арифметике и цикличности последних цифр в степенных башнях.

## 1.7.6. Обратные операции: логарифм и сверхлогарифм

Каждая операция порождает обратные:

| Прямая операция | Обратная (по «результату») | Обратная (по «количеству раз») |
|:-:|:-:|:-:|
| $a + b = c$ | $c - b = a$ (вычитание) | $c - a = b$ (вычитание) |
| $a \times b = c$ | $c \div b = a$ (деление) | $c \div a = b$ (деление) |
| $a^b = c$ | $\sqrt[b]{c} = a$ (корень) | $\log_a c = b$ (логарифм) |
| ${}^{b}a = c$ | $?$ (суперкорень) | $\text{slog}_a\,c = b$ (сверхлогарифм) |

**Сверхлогарифм** (superlogarithm, или итерированный логарифм) $\text{slog}_a(c)$ отвечает на вопрос: «Сколько раз нужно возвести $a$ в степень самого себя, чтобы получить $c$?»

Например, $\text{slog}_2(65536) = 4$, потому что ${}^{4}2 = 65536$.

Сверхлогарифм растёт **невероятно медленно**. Для любого числа, которое человек может встретить в жизни, сверхлогарифм не превышает 5:

| $c$ | $\text{slog}_2(c)$ |
|:---:|:-------------------:|
| $2$ | $1$ |
| $4$ | $2$ |
| $16$ | $3$ |
| $65\,536$ | $4$ |
| $2^{65536}$ (число с $\approx 20\,000$ цифрами) | $5$ |

## 1.7.7. Бесконечные башни степеней

В [§1.6](infinity.md) мы обсуждали, как работать с бесконечностью. Что произойдёт, если высота башни стремится к бесконечности?

$${}^{\infty}x = x^{x^{x^{\cdot^{\cdot^{\cdot}}}}}$$

Удивительно, но для некоторых значений $x$ такая бесконечная башня **сходится** — то есть стремится к конечному числу.

### Когда башня сходится

Бесконечная башня ${}^{\infty}x$ сходится тогда и только тогда, когда

$$e^{-e} \leq x \leq e^{1/e} \qquad (\approx 0.0660 \leq x \leq 1.4447)$$

За пределами этого интервала значения башни конечной высоты либо растут без ограничения, либо осциллируют без сходимости.

### Ключевое наблюдение

Пусть башня сходится к значению $c$:

$${}^{\infty}x = c$$

Тогда «надстройка» башни ещё на один уровень ничего не меняет (башня бесконечна — один лишний уровень не заметен):

$$x^{{}^{\infty}x} = c \qquad \Rightarrow \qquad x^c = c$$

Это **функциональное уравнение**: если мы знаем $c$, то $x = c^{1/c}$. И наоборот: если мы знаем $x$, то $c$ удовлетворяет уравнению $x^c = c$.

### Задача: $x^{x^{x^{\cdots}}} = 2$

Найдём $x$ такое, что бесконечная башня степеней равна 2.

Из уравнения $x^c = c$ при $c = 2$:

$$x^2 = 2 \qquad \Rightarrow \qquad x = \sqrt{2}$$

**Проверка.** Башня $(\sqrt{2})^{(\sqrt{2})^{(\sqrt{2})^{\cdots}}} = 2$. Вычислим несколько уровней:

| $n$ | ${}^{n}\!\sqrt{2}$ |
|:---:|:-------------------:|
| $1$ | $\sqrt{2} \approx 1.4142$ |
| $2$ | $(\sqrt{2})^{\sqrt{2}} \approx 1.6325$ |
| $3$ | $(\sqrt{2})^{1.6325} \approx 1.7608$ |
| $4$ | $(\sqrt{2})^{1.7608} \approx 1.8409$ |
| $5$ | $(\sqrt{2})^{1.8409} \approx 1.8921$ |
| $10$ | $\approx 1.9786$ |
| $20$ | $\approx 1.9998$ |
| $\infty$ | $2$ |

Башня действительно стремится к $2$. Обратите внимание: $\sqrt{2} \approx 1.4142 < e^{1/e} \approx 1.4447$ — входит в область сходимости.

### Задача: $x^{x^{x^{\cdots}}} = 3$

Аналогично, при $c = 3$:

$$x^3 = 3 \qquad \Rightarrow \qquad x = \sqrt[3]{3} = 3^{1/3} \approx 1.4422$$

Проверим: $\sqrt[3]{3} \approx 1.4422 < e^{1/e} \approx 1.4447$ — лишь **чуть-чуть** ниже границы!

| $n$ | ${}^{n}\!\sqrt[3]{3}$ |
|:---:|:---------------------:|
| $1$ | $\sqrt[3]{3} \approx 1.4422$ |
| $2$ | $(\sqrt[3]{3})^{\sqrt[3]{3}} \approx 1.8055$ |
| $3$ | $\approx 2.2735$ |
| $5$ | $\approx 2.7855$ |
| $10$ | $\approx 2.9901$ |
| $20$ | $\approx 2.9999$ |
| $\infty$ | $3$ |

Сходимость здесь медленнее — значение $x$ ближе к верхней границе.

### Общая формула

Для любого $c$ в интервале $\left[\frac{1}{e}, \; e\right]$ (а это границы значений, которые может принимать бесконечная башня) решение уравнения ${}^{\infty}x = c$ равно:

$$\boxed{x = c^{1/c}}$$

| $c$ | $x = c^{1/c}$ | Приближённо |
|:---:|:--------------:|:-----------:|
| $1$ | $1^1 = 1$ | $1$ |
| $2$ | $2^{1/2} = \sqrt{2}$ | $1.4142$ |
| $e$ | $e^{1/e}$ | $1.4447$ |
| $3$ | $3^{1/3} = \sqrt[3]{3}$ | $1.4422$ |
| $4$ | $4^{1/4} = \sqrt[4]{4} = \sqrt{2}$ | $1.4142$ |

Здесь $c = 4$ даёт **то же** $x = \sqrt{2}$, что и $c = 2$!

!!! warning "Парадокс: два ответа для одного $x$?"
    Уравнение $x^c = c$ при $x = \sqrt{2}$ имеет два решения: $c = 2$ и $c = 4$. Однако бесконечная башня ${}^{\infty}\!\sqrt{2}$ сходится к **меньшему** значению $c = 2$. Второе значение $c = 4$ — «паразитное»: оно появляется из алгебры, но не является пределом последовательности ${}^{n}x$.

    В общем случае, если уравнение $x^c = c$ имеет два решения, башня всегда сходится к **меньшему** из них.

### Связь с W-функцией Ламберта

Уравнение $x^c = c$ можно решить и относительно $c$ при данном $x$. Прологарифмируем: $c \ln x = \ln c$, откуда $\frac{\ln c}{c} = \ln x$. Замена $t = -\ln c$:

$$-t \, e^{-t} = \ln x \qquad \Rightarrow \qquad t \, e^t = -\ln x \qquad \Rightarrow \qquad t = W(-\ln x)$$

$$c = e^{-t} = e^{-W(-\ln x)} = \frac{-\ln x}{W(-\ln x)} \cdot \frac{W(-\ln x)}{-\ln x} \cdot e^{-W(-\ln x)}$$

В итоге:

$${}^{\infty}x = -\frac{W(-\ln x)}{\ln x}$$

Это замкнутая формула для значения бесконечной башни через W-функцию Ламберта (подробнее о ней — в §1.11.8).

---

!!! abstract "Резюме главы"
    - Арифметические операции образуют **лестницу**: сложение → умножение → степень → тетрация → пентация → ...
    - Каждая следующая операция — **повторение** предыдущей
    - Тетрация ${}^{n}a$ (башня степеней) растёт несопоставимо быстрее возведения в степень
    - Стрелочная нотация Кнута ($\uparrow$, $\uparrow\uparrow$, $\uparrow\uparrow\uparrow$, ...) — удобный способ записи гиперопераций
    - Число Грэма — пример числа, для описания которого недостаточно даже стрелочной нотации с фиксированным числом стрелок
    - Обратная операция к тетрации — **сверхлогарифм** — растёт невероятно медленно
    - Бесконечная башня ${}^{\infty}x$ сходится при $e^{-e} \leq x \leq e^{1/e}$; уравнение ${}^{\infty}x = c$ решается как $x = c^{1/c}$

---

!!! tip "Что дальше"
    Мы увидели, как повторение операций порождает числа невообразимой величины. Но насколько точно мы можем представить числа в памяти компьютера? В [§1.8 «Числа с плавающей запятой»](floating-point.md) мы узнаем, что даже простая дробь $0.1$ хранится с ошибкой — и разберёмся, почему.
