# Глава 3.3. Тригонометрические уравнения и неравенства

## 3.3.1. Простейшие тригонометрические уравнения

### $\sin x = a$

При $|a| > 1$ решений нет. При $|a| \leq 1$:

$$x = (-1)^n \arcsin a + \pi n, \quad n \in \mathbb{Z}$$

Интуиция: синус принимает значение $a$ в двух точках первого и второго (или третьего и четвёртого) полуоборотов. Формула учитывает симметрию: $\sin(\pi - \alpha) = \sin\alpha$.

Частные случаи:

| Уравнение | Решение |
|:---:|:---|
| $\sin x = 0$ | $x = \pi n$ |
| $\sin x = 1$ | $x = \frac{\pi}{2} + 2\pi n$ |
| $\sin x = -1$ | $x = -\frac{\pi}{2} + 2\pi n$ |
| $\sin x = \frac{1}{2}$ | $x = \frac{\pi}{6} + 2\pi n$ или $x = \frac{5\pi}{6} + 2\pi n$ |

### $\cos x = a$

При $|a| > 1$ решений нет. При $|a| \leq 1$:

$$x = \pm\arccos a + 2\pi n, \quad n \in \mathbb{Z}$$

Косинус симметричен относительно 0, поэтому $\pm$ вместо $(-1)^n$.

| Уравнение | Решение |
|:---:|:---|
| $\cos x = 0$ | $x = \frac{\pi}{2} + \pi n$ |
| $\cos x = 1$ | $x = 2\pi n$ |
| $\cos x = -1$ | $x = \pi + 2\pi n$ |
| $\cos x = \frac{\sqrt{3}}{2}$ | $x = \pm\frac{\pi}{6} + 2\pi n$ |

### $\tan x = a$

Тангенс определён всюду, кроме $x = \frac{\pi}{2} + \pi n$. Для любого $a \in \mathbb{R}$:

$$x = \arctan a + \pi n, \quad n \in \mathbb{Z}$$

Период тангенса — $\pi$ (вдвое меньше периода синуса/косинуса), поэтому только одно семейство.

## 3.3.2. Метод единичной окружности

Уравнения удобно решать геометрически: изобразить единичную окружность и найти все точки, удовлетворяющие условию.

**Пример.** Решить $\sin x = \frac{\sqrt{3}}{2}$ на отрезке $[0, 2\pi]$.

Находим на единичной окружности все точки с $y$-координатой $\frac{\sqrt{3}}{2}$: это углы $60°$ и $120°$ (т.е. $\frac{\pi}{3}$ и $\frac{2\pi}{3}$).

Ответ: $x = \frac{\pi}{3}$ и $x = \frac{2\pi}{3}$.

## 3.3.3. Уравнения, сводящиеся к простейшим

### Линейная замена аргумента

Уравнения вида $\sin(2x + 1) = 0.5$ решаются заменой $t = 2x + 1$:

$$\sin t = 0.5 \quad \Rightarrow \quad t = \frac{\pi}{6} + 2\pi n \text{ или } t = \frac{5\pi}{6} + 2\pi n$$

Возвращаясь: $2x + 1 = \frac{\pi}{6} + 2\pi n$, т.е. $x = \frac{\pi/6 - 1}{2} + \pi n$ (и аналогично второе семейство).

### Однородные уравнения

**Однородное уравнение** содержит только функции $\sin x$ и $\cos x$ одной и той же суммарной степени.

**I степень:** $a\sin x + b\cos x = 0$. Делим на $\cos x$ (проверив, что $\cos x \neq 0$):

$$a\tan x + b = 0 \quad \Rightarrow \quad \tan x = -\frac{b}{a}$$

**II степень:** $a\sin^2 x + b\sin x\cos x + c\cos^2 x = 0$. Делим на $\cos^2 x$:

$$a\tan^2 x + b\tan x + c = 0$$

Это квадратное уравнение относительно $\tan x$.

**Пример.** Решить $\sin^2 x - \sin x\cos x - 2\cos^2 x = 0$.

Делим на $\cos^2 x$: $\tan^2 x - \tan x - 2 = 0$.

$$(\tan x - 2)(\tan x + 1) = 0 \quad \Rightarrow \quad \tan x = 2 \text{ или } \tan x = -1$$

$$x = \arctan 2 + \pi n \quad \text{или} \quad x = -\frac{\pi}{4} + \pi n$$

### Уравнения, сводящиеся к квадратным

**Пример.** Решить $2\sin^2 x + \sin x - 1 = 0$.

Замена $t = \sin x$: $2t^2 + t - 1 = 0$, откуда $(2t - 1)(t + 1) = 0$.

$t = \frac{1}{2}$: $\sin x = \frac{1}{2}$, т.е. $x = \frac{\pi}{6} + 2\pi n$ или $x = \frac{5\pi}{6} + 2\pi n$.

$t = -1$: $\sin x = -1$, т.е. $x = -\frac{\pi}{2} + 2\pi n$.

**Важно:** обязательно проверить, что $|t| \leq 1$ (иначе $\sin x = t$ не имеет решений).

## 3.3.4. Метод вспомогательного аргумента в уравнениях

Уравнение $a\sin x + b\cos x = c$ решается методом главы 3.2:

$$\sqrt{a^2+b^2}\sin(x + \varphi) = c, \quad \tan\varphi = \frac{b}{a}$$

$$\sin(x + \varphi) = \frac{c}{\sqrt{a^2+b^2}}$$

Уравнение имеет решения тогда и только тогда, когда $|c| \leq \sqrt{a^2+b^2}$.

**Пример.** Решить $\sin x + \cos x = 1$.

$\sqrt{2}\sin\!\left(x + \frac{\pi}{4}\right) = 1$, т.е. $\sin\!\left(x + \frac{\pi}{4}\right) = \frac{1}{\sqrt{2}}$.

$x + \frac{\pi}{4} = \frac{\pi}{4} + 2\pi n \Rightarrow x = 2\pi n$, или $x + \frac{\pi}{4} = \frac{3\pi}{4} + 2\pi n \Rightarrow x = \frac{\pi}{2} + 2\pi n$.

## 3.3.5. Отбор корней на промежутке

Общая формула даёт бесконечно много корней; задача часто требует найти корни на конкретном промежутке.

**Алгоритм:**
1. Записать общее решение.
2. Подставить значения $n = \ldots, -1, 0, 1, 2, \ldots$ и выбрать те $x$, которые попадают в нужный промежуток.

**Пример.** Решить $\cos x = \frac{1}{2}$ на $[-\pi, \pi]$.

Общее решение: $x = \pm\frac{\pi}{3} + 2\pi n$.

При $n = 0$: $x = \frac{\pi}{3}$ и $x = -\frac{\pi}{3}$ — оба в $[-\pi, \pi]$. ✓

При $n = 1$: $x = \frac{\pi}{3} + 2\pi \approx 7.6$ — не входит. При $n = -1$: $x = -\frac{\pi}{3} - 2\pi \approx -7.6$ — не входит.

Ответ: $x = \pm\frac{\pi}{3}$.

## 3.3.6. Тригонометрические неравенства

### Неравенства для синуса и косинуса

Неравенство $\sin x > a$ (при $|a| < 1$) решается геометрически: нужны те точки единичной окружности, где $y$-координата **больше** $a$. Это дуга от $\arcsin a$ до $\pi - \arcsin a$:

$$\sin x > a \quad \Leftrightarrow \quad \arcsin a + 2\pi n < x < \pi - \arcsin a + 2\pi n, \quad n \in \mathbb{Z}$$

Для $\cos x > a$: нужны точки с $x$-координатой больше $a$, т.е. дуга около $x = 0$:

$$\cos x > a \quad \Leftrightarrow \quad -\arccos a + 2\pi n < x < \arccos a + 2\pi n, \quad n \in \mathbb{Z}$$

!!! tip "Метод единичной окружности"
    Нарисуйте единичную окружность и проведите горизонтальную (для $\sin$) или вертикальную (для $\cos$) линию на высоте $a$. Нужная дуга — та часть окружности, которая находится выше (или ниже) этой линии.

### Пример

Решить $2\sin^2 x - 3\sin x + 1 \leq 0$.

Замена $t = \sin x$: $2t^2 - 3t + 1 \leq 0$, т.е. $(2t-1)(t-1) \leq 0$.

Это выполняется при $\frac{1}{2} \leq t \leq 1$, то есть $\frac{1}{2} \leq \sin x \leq 1$.

- $\sin x \geq \frac{1}{2}$: $\frac{\pi}{6} + 2\pi n \leq x \leq \frac{5\pi}{6} + 2\pi n$.
- $\sin x \leq 1$: выполнено всегда.

Ответ: $\frac{\pi}{6} + 2\pi n \leq x \leq \frac{5\pi}{6} + 2\pi n$, $n \in \mathbb{Z}$.

## 3.3.7. Важные нетривиальные уравнения

### Уравнение $\sin x = \sin y$

$$\sin x = \sin y \quad \Leftrightarrow \quad \begin{cases} x = y + 2\pi n \\ \text{или} \\ x = \pi - y + 2\pi n \end{cases}$$

### Уравнение $\cos x = \cos y$

$$\cos x = \cos y \quad \Leftrightarrow \quad x = \pm y + 2\pi n$$

### Уравнение $\tan x = \tan y$

$$\tan x = \tan y \quad \Leftrightarrow \quad x = y + \pi n$$

Эти формулы полезны при решении систем уравнений и уравнений с параметром.

---

!!! abstract "Резюме главы"
    - Простейшие уравнения $\sin x = a$, $\cos x = a$, $\tan x = a$ имеют явные формулы для общего решения
    - Метод единичной окружности — геометрическая альтернатива формулам
    - Однородные уравнения и уравнения вида $a\sin x + b\cos x = c$ сводятся к простейшим заменой переменной или методом вспомогательного аргумента
    - Уравнения с $\sin^2 x$ и $\cos^2 x$ сводятся к квадратным через замену
    - Тригонометрические неравенства решаются через единичную окружность: нужно найти дугу, удовлетворяющую условию
    - При нахождении корней на промежутке — перебирать $n$ и проверять принадлежность
