# Глава 9.1. Классические неравенства и методы доказательства

## 9.1.1. Неравенство о средних (AM-GM)

**Среднее арифметическое** и **среднее геометрическое** двух неотрицательных чисел $a, b$:

$$A = \frac{a+b}{2}, \qquad G = \sqrt{ab}$$

!!! important "Неравенство AM-GM для двух чисел"
    Для любых $a, b \geq 0$:
    $$\frac{a+b}{2} \geq \sqrt{ab}$$
    с равенством тогда и только тогда, когда $a = b$.

**Доказательство.** $\frac{a+b}{2} - \sqrt{ab} = \frac{a - 2\sqrt{ab} + b}{2} = \frac{(\sqrt{a}-\sqrt{b})^2}{2} \geq 0$. $\blacksquare$

### Обобщение на $n$ чисел

Для $n$ неотрицательных чисел $a_1, \ldots, a_n$:

$$\frac{a_1 + a_2 + \cdots + a_n}{n} \geq \sqrt[n]{a_1 a_2 \cdots a_n}$$

Равенство — только при $a_1 = a_2 = \cdots = a_n$.

**Полная цепочка средних** (при $a_i \geq 0$, не все нули):

$$H \leq G \leq A \leq Q$$

где $H = \dfrac{n}{\sum 1/a_i}$ — гармоническое, $G = \sqrt[n]{\prod a_i}$ — геометрическое, $A = \dfrac{\sum a_i}{n}$ — арифметическое, $Q = \sqrt{\dfrac{\sum a_i^2}{n}}$ — среднеквадратичное.

### Применение AM-GM

**Задача.** Доказать, что $x^2 + y^2 \geq 2xy$ для всех вещественных $x, y$.

Из AM-GM для $a = x^2$, $b = y^2$: $\frac{x^2+y^2}{2} \geq \sqrt{x^2 y^2} = |xy| \geq xy$. ✓

**Задача.** Найти минимум $f(x) = x + \frac{1}{x}$ при $x > 0$.

AM-GM: $x + \frac{1}{x} \geq 2\sqrt{x \cdot \frac{1}{x}} = 2$. Минимум $= 2$, достигается при $x = 1$.

**Задача.** При $a + b + c = 1$, $a, b, c > 0$, найти максимум $abc$.

AM-GM: $\frac{a+b+c}{3} \geq \sqrt[3]{abc}$, то есть $\frac{1}{3} \geq \sqrt[3]{abc}$, то есть $abc \leq \frac{1}{27}$. Максимум достигается при $a = b = c = \frac{1}{3}$.

## 9.1.2. Неравенство Коши–Буняковского

!!! important "Неравенство Коши–Буняковского (Schwarz)"
    Для вещественных $a_1, \ldots, a_n$ и $b_1, \ldots, b_n$:
    
    $$(a_1 b_1 + a_2 b_2 + \cdots + a_n b_n)^2 \leq (a_1^2 + \cdots + a_n^2)(b_1^2 + \cdots + b_n^2)$$

**Доказательство (Лагранж).** Рассмотрим функцию $f(t) = \sum(a_i t - b_i)^2 \geq 0$. Раскроем: $f(t) = (\sum a_i^2)t^2 - 2(\sum a_i b_i)t + \sum b_i^2 \geq 0$. Дискриминант $\leq 0$: $4(\sum a_i b_i)^2 \leq 4(\sum a_i^2)(\sum b_i^2)$. $\blacksquare$

**Форма Энгеля / Тит–Три (Sedrakyan / Titu):**

$$\frac{a_1^2}{b_1} + \frac{a_2^2}{b_2} + \cdots + \frac{a_n^2}{b_n} \geq \frac{(a_1 + a_2 + \cdots + a_n)^2}{b_1 + b_2 + \cdots + b_n}$$

(при $b_i > 0$). Это прямое следствие Коши–Буняковского с заменой $a_i \to a_i/\sqrt{b_i}$.

**Задача.** Доказать: $\frac{a^2}{b+c} + \frac{b^2}{a+c} + \frac{c^2}{a+b} \geq \frac{a+b+c}{2}$ при $a, b, c > 0$.

По форме Энгеля: $\frac{a^2}{b+c} + \frac{b^2}{a+c} + \frac{c^2}{a+b} \geq \frac{(a+b+c)^2}{2(a+b+c)} = \frac{a+b+c}{2}$. ✓

## 9.1.3. Неравенство Йенсена

!!! important "Неравенство Йенсена"
    Если $f$ **выпуклая** функция (т.е. $f''(x) \geq 0$), то для любых $x_1, \ldots, x_n$ и весов $\lambda_i \geq 0$ с $\sum \lambda_i = 1$:
    
    $$f\!\left(\sum_{i=1}^n \lambda_i x_i\right) \leq \sum_{i=1}^n \lambda_i f(x_i)$$
    
    Для **вогнутой** $f$ знак неравенства меняется.

**Применения.**

Из выпуклости $-\ln$: $-\ln\frac{\sum x_i}{n} \leq \frac{-\sum \ln x_i}{n}$, т.е. $\ln\frac{\sum x_i}{n} \geq \frac{\sum \ln x_i}{n}$, т.е. $\frac{\sum x_i}{n} \geq \sqrt[n]{\prod x_i}$ — **AM-GM**.

Из вогнутости $\sin$ на $(0,\pi)$: для углов треугольника $A+B+C=\pi$,

$$\sin A + \sin B + \sin C \leq 3\sin\frac{A+B+C}{3} = 3\sin 60° = \frac{3\sqrt{3}}{2}$$

## 9.1.4. Неравенство Шура

!!! important "Неравенство Шура"
    Для неотрицательных $a, b, c$ и $t > 0$:
    
    $$a^t(a-b)(a-c) + b^t(b-a)(b-c) + c^t(c-a)(c-b) \geq 0$$

При $t=1$: $a(a-b)(a-c) + b(b-a)(b-c) + c(c-a)(c-b) \geq 0$.

Равенство при $a=b=c$ и при двух из трёх переменных равных нулю (например, $a = b$, $c = 0$).

Раскрывая при $t=1$: $a^3+b^3+c^3+abc \geq ab(a+b)+bc(b+c)+ca(c+a)$.

## 9.1.5. Методы доказательства неравенств

### Метод подстановки

Заменить переменные так, чтобы условие стало тривиальным.

**Пример.** Доказать $\frac{1}{1+a} + \frac{1}{1+b} \geq \frac{2}{1+\sqrt{ab}}$ при $a, b > 0$.

Пусть $a = x^2$, $b = y^2$ (без ограничения общности $x, y > 0$). Тогда надо доказать:

$$\frac{1}{1+x^2} + \frac{1}{1+y^2} \geq \frac{2}{1+xy}$$

Это можно проверить напрямую: разность знаменателей...

### Метод SOS (Sum of Squares)

Представить неравенство как сумму квадратов — она всегда неотрицательна.

**Пример.** $a^2 + b^2 + c^2 \geq ab + bc + ca$.

$$a^2+b^2+c^2-ab-bc-ca = \frac{(a-b)^2+(b-c)^2+(c-a)^2}{2} \geq 0$$

### Метод сглаживания (Smoothing / Mixing variables)

Если неравенство симметрично, то экстремум достигается, когда переменные «как можно более равны» или «как можно более крайние».

**Принцип.** Если $f(a_1, \ldots, a_n)$ достигает минимума при фиксированной сумме $\sum a_i = S$, то в точке минимума все $a_i$ равны (для выпуклых функций) или принимают крайние значения (для некоторых задач).

**Пример.** Максимум $abc$ при $a+b+c=1$, $a,b,c \geq 0$. Если $a \neq b$, заменим оба на $\frac{a+b}{2}$: произведение $abc \to \left(\frac{a+b}{2}\right)^2 c \geq \frac{ab}{1}\cdot c = abc$ (по AM-GM: $\left(\frac{a+b}{2}\right)^2 \geq ab$). Значит, максимум достигается при $a = b$. Аналогично $a = b = c$.

### Метод Мурхеда (мажорирование)

Для симметрических неравенств вида «$[p_1, p_2, p_3] \geq [q_1, q_2, q_3]$», где

$$[p_1, p_2, p_3] = \sum_{\text{перест.}} a^{p_1}b^{p_2}c^{p_3}$$

неравенство выполняется тогда и только тогда, когда вектор $(p_1, p_2, p_3)$ **мажорирует** $(q_1, q_2, q_3)$ (при условии убывающей сортировки):

$$p_1 \geq q_1, \quad p_1+p_2 \geq q_1+q_2, \quad p_1+p_2+p_3 = q_1+q_2+q_3$$

**Пример.** Доказать $a^3 + b^3 + c^3 \geq a^2 b + b^2 c + c^2 a$.

$[3,0,0] \geq [2,1,0]$? $3 \geq 2$, $3+0 \geq 2+1$, суммы равны. Мажорирование выполнено — неравенство истинно. ✓

!!! abstract "Резюме главы"
    - **AM-GM**: $\frac{a_1+\cdots+a_n}{n} \geq \sqrt[n]{a_1\cdots a_n}$; равенство при равных
    - **Коши–Буняковского**: $(\sum a_i b_i)^2 \leq (\sum a_i^2)(\sum b_i^2)$; форма Энгеля (Titu)
    - **Йенсена**: $f(\bar{x}) \leq \overline{f(x)}$ для выпуклой $f$
    - **Шура**: $a^t(a-b)(a-c)+\cdots \geq 0$
    - **Методы**: SOS, сглаживание, мажорирование Мурхеда
