# План развития учебника «Дополнительные главы школьной математики»

Этот документ содержит план по добавлению новых глав и тем, выбранных для первоочередной работы. Задачи можно отмечать галочками по мере написания.

## Глава 1. Расширение темы чисел (ch1)

В первую главу (или как отдельные логические блоки в начале) добавим фундаментальные понятия о числах:

- [x] **Делимость и простые числа**
  - Признаки делимости.
  - НОД, НОК, Алгоритм Евклида.
  - Основная теорема арифметики.
- [ ] **Виды чисел**
  - Рациональные числа (периодические дроби).
  - Иррациональные числа (доказательство иррациональности $\sqrt{2}$).
  - Трансцендентные числа (понятие об $e$ и $\pi$, различие с алгебраическими иррациональностями).
- [ ] **Комплексные числа**
  - Мнимая единица, алгебраическая форма.
  - Геометрический смысл и тригонометрическая форма.

## Глава 2. Расширение темы алгебры (ch2)

Дополняем главу про уравнения:

- [ ] **Системы уравнений**
  - Нестандартные методы решения.
  - Симметрические системы.
  - Однородные системы уравнений.

## Глава 4. Комбинаторика (Новая глава — ch4)

Создаём новую главу, посвященную олимпиадной комбинаторике:

- [ ] **Основы комбинаторики**
  - Правило суммы и правило произведения.
  - Перестановки, размещения, сочетания (понятие факториала и $C_n^k$).
- [ ] **Бином Ньютона**
  - Треугольник Паскаля и свойства биномиальных коэффициентов.
  - Формула бинома Ньютона.
- [ ] **Принцип Дирихле**
  - Базовая формулировка ("зайцы и клетки").
  - Обобщенный принцип Дирихле и нестандартные олимпиадные задачи.
