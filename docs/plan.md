## Глава 6. Алгоритмическая сложность (Новая глава)

- [x] **O-нотация (Big-O)**
  - Зачем измерять: одна задача, два алгоритма — один быстрый, другой медленный. Как сравнивать, не привязываясь к конкретному компьютеру?
  - Определение $O(f(n))$: верхняя оценка роста, игнорируем константы и младшие члены.
  - Основные классы: $O(1)$, $O(\log n)$, $O(n)$, $O(n \log n)$, $O(n^2)$, $O(2^n)$, $O(n!)$.
  - Сравнительная таблица: при $n = 10, 100, 1000, 10^6$.
- [x] **Сложность по времени**
  - Линейный поиск ($O(n)$) vs бинарный поиск ($O(\log n)$).
  - Сортировка пузырьком ($O(n^2)$) vs сортировка слиянием ($O(n \log n)$).
  - Почему $O(n \log n)$ — нижняя граница для сортировки сравнениями.
- [x] **Сложность по памяти**
  - Что считаем: дополнительная память сверх входных данных.
  - Примеры: обход массива ($O(1)$ памяти), рекурсия ($O(n)$ — стек вызовов), матрица расстояний ($O(n^2)$).
  - Компромисс время–память (time–space tradeoff): хеш-таблица ускоряет поиск за счёт памяти.
- [x] **Практические примеры**
  - Алгоритм Евклида: $O(\log(\min(a,b)))$ — связь с числами Фибоначчи (наихудший случай).
  - Решето Эратосфена: $O(n \log \log n)$ по времени, $O(n)$ по памяти.
  - Задача «два числа с заданной суммой»: от $O(n^2)$ перебора к $O(n)$ с хеш-таблицей.
- [x] **Игра «Жизнь» Конвея** (глава 6.4)
  - Правила клеточного автомата.
  - Базовые паттерны: натюрморты, осцилляторы, космические корабли.
  - Эмерджентность: сложное поведение из простых правил.
  - Универсальность и полнота по Тьюрингу.
  - Обобщение: другие клеточные автоматы.

## Новая часть: Решение задач

- [x] **Лжецы, правдецы и логические загадки** (глава)
  - Введение: остров лжецов и правдецов — правила мира.
  - Базовые задачи: определить, кто лжец, а кто правдец, по высказываниям.
  - Задача двух дверей: одна ведёт к свободе, другая — к гибели; один стражник всегда лжёт, другой всегда говорит правду. Какой один вопрос задать?
  - Усложнения: три стражника (один случайный), стражники на неизвестном языке (загадка Будса).
  - Задачи с несколькими высказываниями и цепочками логических выводов.
  - Хамелеоны и шпионы: вариации, когда тип персонажа может меняться или зависит от контекста.

- [x] **Задачи на взвешивание** (глава)
  - Классическая задача: найти фальшивую монету среди $n$ монет за минимальное число взвешиваний на чашечных весах без гирь.
  - 8 монет, одна легче — 2 взвешивания. 12 монет, одна отличается (неизвестно, легче или тяжелее) — 3 взвешивания.
  - Информационная оценка: каждое взвешивание даёт один из трёх исходов — связь с троичной системой счисления.
  - Обобщение: $n$ монет с $k$ фальшивыми.
  - Задачи с пружинными весами (точное взвешивание): разбить набор гирь, отмерить нужный вес.
  - Задача Баше о гирях: какие гири нужны, чтобы взвесить любой целый вес от 1 до $n$?
  - Стратегии и деревья решений: как записывать алгоритм взвешиваний.

- [x] **Арифметические головоломки** (глава)
  - Задачи «угадай числа»: известно произведение и/или сумма двух (или нескольких) чисел — найти сами числа. Классика: «Я не знаю числа» — «Теперь и я знаю».
  - Криптарифмы: SEND + MORE = MONEY и подобные — замена букв на цифры.
  - Сложение и умножение в столбик с пропущенными цифрами: восстановить пример, зная лишь часть цифр.
  - Ребусы с числами: расстановка цифр 1–9 по клеткам, магические квадраты, магические треугольники.
  - Делимость как инструмент: использование признаков делимости и чётности для сужения перебора.

- [x] **Задачи на смекалку и нестандартное мышление** (глава)
  - Задача кузнеца (разрывы цепи): цепь из $n$ звеньев, разломать минимальное количество звеньев, чтобы платить по одному звену в день.
  - Спуск с горы: скала высотой 100 м, дерево на высоте 50 м, верёвка длиной 75 м — как спуститься?
  - Переправа через квадратный ров: ров шириной $d$, есть две доски длиной чуть меньше $d$ — как перебраться?
  - Переправы и перевозки: волк, коза и капуста; ревнивые мужья; миссионеры и каннибалы.
  - Разрезания и перекладывания: разрезать фигуру на части и сложить другую (задачи типа танграм).
  - Переливания: из сосудов 3 л и 5 л отмерить ровно 4 л.
  - Задачи со спичками: переложить / убрать спичку, чтобы равенство стало верным.
  - Подсчёт рукопожатий, отрезков, диагоналей: комбинаторные задачи, маскирующиеся под задачи на смекалку.

- [x] **Задачи с «недостающими» данными** (глава)
  - Введение: задачи, в которых кажется, что данных не хватает для решения, но на самом деле лишние неизвестные сокращаются.
  - Задача про уборку снега: Яна убрала 400 кг, потом втроём работали до остатка 200 кг, потом доделала одна; закончила в 4 часа — за сколько справилась бы одна? (Общая масса снега не задана — и не нужна.)
  - Задача о двух старушках: вышли на рассвете навстречу друг другу, встретились в полдень; одна пришла в 16:00, вторая в 21:00 — во сколько был рассвет? (Расстояние и скорости не заданы.)
  - Задача о поезде и мухе: два поезда едут навстречу, муха летает между ними — какой путь пролетит муха? (Длина пути мухи не требует суммирования ряда.)
  - Задача о верёвке вокруг Земли: верёвку, обёрнутую вокруг экватора, удлинили на 1 м — на сколько она поднимется? (Радиус Земли не нужен.)
  - Задача о пауке и мухе на стенах комнаты: кратчайший путь по поверхности — развёртка прямоугольного параллелепипеда.
  - Почему это работает: размерный анализ, сокращение параметров, замена переменных; как заметить, что «лишнее» неизвестное уйдёт.
