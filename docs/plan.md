## Глава 6. Алгоритмическая сложность (Новая глава)

- [x] **O-нотация (Big-O)**
  - Зачем измерять: одна задача, два алгоритма — один быстрый, другой медленный. Как сравнивать, не привязываясь к конкретному компьютеру?
  - Определение $O(f(n))$: верхняя оценка роста, игнорируем константы и младшие члены.
  - Основные классы: $O(1)$, $O(\log n)$, $O(n)$, $O(n \log n)$, $O(n^2)$, $O(2^n)$, $O(n!)$.
  - Сравнительная таблица: при $n = 10, 100, 1000, 10^6$.
- [x] **Сложность по времени**
  - Линейный поиск ($O(n)$) vs бинарный поиск ($O(\log n)$).
  - Сортировка пузырьком ($O(n^2)$) vs сортировка слиянием ($O(n \log n)$).
  - Почему $O(n \log n)$ — нижняя граница для сортировки сравнениями.
- [x] **Сложность по памяти**
  - Что считаем: дополнительная память сверх входных данных.
  - Примеры: обход массива ($O(1)$ памяти), рекурсия ($O(n)$ — стек вызовов), матрица расстояний ($O(n^2)$).
  - Компромисс время–память (time–space tradeoff): хеш-таблица ускоряет поиск за счёт памяти.
- [x] **Практические примеры**
  - Алгоритм Евклида: $O(\log(\min(a,b)))$ — связь с числами Фибоначчи (наихудший случай).
  - Решето Эратосфена: $O(n \log \log n)$ по времени, $O(n)$ по памяти.
  - Задача «два числа с заданной суммой»: от $O(n^2)$ перебора к $O(n)$ с хеш-таблицей.
- [x] **Игра «Жизнь» Конвея** (глава 6.4)
  - Правила клеточного автомата.
  - Базовые паттерны: натюрморты, осцилляторы, космические корабли.
  - Эмерджентность: сложное поведение из простых правил.
  - Универсальность и полнота по Тьюрингу.
  - Обобщение: другие клеточные автоматы.
