# Дополнительные главы школьной математики

> Углублённое изучение математики за рамками стандартной программы

Эта книга — **руководство и справочник** для тех, кто хочет выйти за рамки школьного учебника. Мы разберём темы, которые редко встречаются в стандартной программе, но необходимы для олимпиад, поступления в сильные вузы и глубокого понимания математики.

Части можно читать последовательно или по мере необходимости. Внутри каждой части материал выстроен от простого к сложному. Каждая тема содержит теорию, разобранные примеры и задачи для самостоятельного решения.
